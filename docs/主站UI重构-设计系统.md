# 主站 UI 重构 · 设计系统

> 方向：还原《率土之滨》官方质感。三原色 = **玄黑（深邃谋略）+ 绛红（征伐热血）+ 蚕白（文臣风骨）**，水墨笔触 / 泼墨晕染 / 扁平轻薄，替换当前「深褐底 + 暗金 + 米黄」皮肤。
> 范围：只重构主站（`index.html` 配将台 + 战报主线）；~10 个独立页（damage-model / round-model / optimize / optimizer / battle-sim / advisor / advisor-lab / rogue）不在本次范围。
> 交付形态：**先定本设计系统 → 用户确认 → 逐页迁移**。骨架（三栏配将台）微调不重造。

---

## 0. form 推导五问

| 问 | 答 |
|---|---|
| **叙事角色** | 工具界面（workbench + 数据呈现），不是叙事页——信息密度与可读性优先 |
| **观众距离** | 1m 桌面/笔记本 + 10cm 手机（横屏为主）；桌面高密度、手机触控目标放大 |
| **视觉温度** | 权威 + 冷静 + 古典（「军师帐」的感觉）——低饱和、克制、不兴奋 |
| **容量估算** | 高信息密度；现有三栏骨架已验证可用，只做皮肤与组件收敛，不改信息结构 |
| **视觉母题** | 汉代军旅「**印信 + 兵符 + 水墨**」——方印（率字 logo、胜/平/负印）、竖笔书签 tab、水墨线条图标 |

> **form 来自内容的哪里**：率土的标志性视觉是「印」（君主印信、胜负印）与「兵符」；水墨笔触是它区别于其他 SLG 的识别度来源。设计系统的一切（方印 logo、竖笔 tab、1.6px 圆头线条图标、玄黑底）都从这个母题长出来，不是套「暗色游戏风」模板。

## 1. 色彩（已过 4.5:1 对比度校验）

全部通过 `var(--color-*)` 引用，不写裸 hex。

### 玄黑 · 表面（页面底 → 抬升，silk 暖灰 ramp 暗端）

| token | 值 | 用途 |
|---|---|---|
| `--color-bg` | `#1f1411` | 页面底 |
| `--color-surface` | `#352722` | 面板 / 顶底栏 |
| `--color-surface-2` | `#4c3c35` | 卡面 / 弹窗 |
| `--color-surface-3` | `#625349` | 最高抬升 / hover |

### 蚕白 · 文字（三档）

| token | 值 | 用途 | 对比度（对 bg） |
|---|---|---|---|
| `--color-text` | `#e4e2d3` | 主文字 | 13.8:1 |
| `--color-text-dim` | `#aca391` | 次文字 | 7.2:1 |
| `--color-text-weak` | `#8f8270` | 三级文字 | 4.8:1 |

### 绛红 · 强调 / 主操作（crimson ramp）

| token | 值 | 用途 |
|---|---|---|
| `--color-crimson` | `#b02330` | hover / 强调线 |
| `--color-crimson-deep` | `#9f1a25` | **主按钮底**（对蚕白 6.09:1） |
| `--color-crimson-darker` | `#8e111a` | 深档 |
| `--color-crimson-tint` | `#7c0910` | 暗底 tint（danger hover） |

### 线

`--color-line` `#4c3c35`（1px 分割线）· `--color-line-strong` `#625349`（边框）

### 保留项（数据色，不随皮肤变）

- 品级 S/A/B/C/D、红方/蓝方队伍色 —— 它们是「数据」不是「皮肤」，迁移时**不动**。

### 关键结论（已实测，勿再改）

1. 绛红**只做填充按钮 / 强调线 / 印章**，**不做小号文字**——`#b02330` 作文字在玄黑底上对比度不足。
2. 主按钮底用 `#9f1a25`（不是更亮的 `#b02330`），保证 6.09:1；hover 才提亮到 500。
3. 蚕白是**暖灰**（不是纯白），三级文字 `#8f8270` 已到 4.8:1，再暗（`#796a5c`）就低于 4.5:1，**不可用**。

## 2. 排版

- 字型：展示用 **Noto Serif SC（楷体质感，率土书签）**，正文用 **PingFang SC / Microsoft YaHei**（密度优先）。
- 字重：**只两档** 400/500（常规）+ 600/700（强调）。绝不下到 400 以下。
- 字阶（px）：`12 14 16 18 20 24 30 36`（页标题/胜负用 36，正文 14，辅助 12）。
- 三级文字：蚕白 `--color-text` / 灰 `--color-text-dim` / 浅灰 `--color-text-weak`。

---

## 3. 按钮系统（本次最大改动：收敛 9 种 → 1 基类 + 4 变体 + 3 尺寸）

**现状问题**：`.btn`(金底) / `.primary`(绯红) / `.beige`(米黄) / `.ghost`(透明) / `.done` / `.nav-link` / `.filter-tag` / `.rbtn` / `.rtab` 九种并存，尺寸不一。

**目标**：

```
.btn           基类：inline-flex + 楷体 600 + 统一高 36px + 圆角 6px + focus 环
  尺寸          .btn-sm(28) / 默认(36) / .btn-lg(44)
  变体
    .primary    绛红填充（每屏唯一主操作）
    .secondary  玄黑 surface-2 填充（次要操作）
    .tertiary   透明（三级操作 / 面板动作）
    .danger     透明 + 破坏性（hover 转绛红 tint，默认不喧哗）
  .btn.icon    36px 正方触控目标
```

- **每屏一个主操作**（primary）：配将台 = 「开始模拟」；伤害实验室 = 「模拟五十次」。
- 现有 `#start`、`#save-preset`、面板按钮等迁移时按语义映射到上述四档，不再各写各的。
- 触控目标 ≥ 36px（refactoring-ui `15-beyond-the-book.md`）。

## 4. 手绘图标（code-drawn，用户点名）

- 一套内联 SVG 线条图标：**24×24 viewBox · 1.6px 描边 · 圆头线帽 · `currentColor` 继承文字色**。
- 覆盖：搜索 / 关闭 / 筛选 / 添加 / 设置 / 返回 / 展开 / 更多 / 列表 / 统计 / 复用 / 公告 等。
- 替换散落的**文字按钮**（如「关闭」「＋」）与缺失图标；图标一律走 token 色，不写死色值。
- **印章式标志单独处理**（见 §5），不走线条图标——印是率土的核心识别。

---

## 5. 印章 / 兵符

- 「率」logo = 方印底 + 楷体竖笔（`--color-crimson-deep` 底）。
- 战报胜负 = 方印 + 竖笔「胜 / 平 / 负」（胜绛红、平灰、负浅灰）。

## 6. 迁移顺序（确认后逐页执行）

1. `web/styles.css` 的 `:root` token 块整体替换 → 加统一 `.btn` 基类 + 图标基类。
2. 主站配将台（顶栏 / 三栏 / 底栏）+ 战报主流程换皮，**骨架不动**。
3. `web/mobile.css` 同步换色 + 触控目标，保持现有横屏单屏 / 竖屏滚动策略不变。
4. 独立页不在本次范围，后续单独迁。

### 迁移纪律

- 只改皮肤与组件收敛，**不改信息结构 / 不改 DOM 语义 / 不改引擎**。
- `mobile.css` 第 394 行附近有历史 GBK 注释（非法 UTF-8），`edit`/`write` 会拒绝——改它用字节级 Buffer 操作。
- 改完跑 `npx tsc --noEmit` + `npx tsc -p web --noEmit` + `npm test`（web smoke 有 CSS 源断言，注意同步）。
- 品级色 / 红蓝队伍色是数据色，**保留不动**。
