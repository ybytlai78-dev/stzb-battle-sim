## 五、上线流程

**主战法实现（每个战法一次提交）**
1. `src/data/skills.ts` 加定义（tags 齐备）+ `scripts/build_heroes_seed.mjs` 的 `SKILL_ID_BY_NAME` 加映射；
2. `node scripts/build_heroes_seed.mjs` → `node scripts/seed_db.mjs` → `node scripts/export_web_data.mjs`；
3. `node scripts/gen_skill_data.mjs`（补品级/描述，缺则 `web/dataIntegrity.test.ts` 失败）；
4. 写 `tests/main_skills_bN.test.ts`（每战法 3 测试）→ `npx tsc --noEmit` + `npm test`；
5. 提交；上线另跑 `bash scripts/deploy-gh-pages.sh`。

**成长率核实（②/③/四类）**：核实数值 → 从 `listing.ts` 移除该条 → 跑测试 → 提交。

> MySQL 不可用时，可用 `node scripts/sync_hero_mainskill.mjs <heroId> <skillId>` 等效同步导出产物。
