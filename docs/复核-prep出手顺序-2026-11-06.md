## 四、一类指挥 prep 改速的覆盖机制（重排三·逐个）

一类指挥 `phase:'prep'` 战法自身也会改速度（其疾如风 +41 我军全体、魏武之世 −15% 敌军全体），
它们的速度写入发生在命令循环内部（`triggerCommandSkills`），循环外再重排已来不及——但代码并非「无第三次重排」，
而是用「重排三·逐个」逐体覆盖：

```ts
// combat.ts:190-202
for (let index = 0; index < turnOrder.length; index += 1) {
  const unit = turnOrder[index];
  if (unit.inert) continue;
  triggerCommandSkills(ctx, unit);                                                // :197 施加（含速度变化）
  if (index + 1 >= turnOrder.length) break;                                       // :198 最后一个，无尾部
  const tailIds = new Set(turnOrder.slice(index + 1).map((u) => u.general.id));  // :199 锁定未执行尾部
  const fresh = buildTurnOrder([...myTeam, ...enemyTeam], turnOrderTieBreaks);    // :200 按最新速度重排
  turnOrder.splice(index + 1, Number.MAX_SAFE_INTEGER, ...fresh.filter((u) => tailIds.has(u.general.id))); // :201 回填尾部
}
```

**覆盖判定（逐条，有行号）**：
- 其疾如风（`src/data/skills.ts:1568`，`initialOutput` speed +41）：由 `combat.ts:197` `triggerCommandSkills` 施加后，
  `combat.ts:200` 的 `buildTurnOrder` 读实时 `effectiveStat(speed)`（`combat.ts:362-363`）把受 +41 的我军单位排前，
  `combat.ts:201` 的 `splice` 把新序写回未执行尾部。
- 魏武之世（`src/data/skills.ts:1751`，`output` speed −15%）：同上，敌军单位被 −15% 后在 `:200` 重排时后移，`:201` 回填尾部。

**设计约束（`combat.ts:190-193` 注释的固有语义）**：
- **只重排「尚未执行」的尾部**：`:199` `tailIds = slice(index + 1)`，`:201` 从 `index + 1` 起 `splice`；
- **已执行顺序不倒带**（既成事实）；不含速度变化的战法重排结果相同，零副作用。

**核实过的边界（非缺陷）**：
- `tailIds` 用 `u.general.id` 作键是安全的：`ensureUniqueUnitIds`（`combat.ts:35-60`）已把红蓝同名武将全局唯一化
  （重复副本改写为 `原id#2`…），不存在同名 id 串味；`buildTurnOrder`（`combat.ts:357-370`）按 `effectiveStat` 排序、
  不改变单位集合，故 `fresh.filter(tailIds)` 数量与尾部一致，`splice` 不改变 `turnOrder.length`，循环推进正确。
- 同一 unit 在一次 `triggerCommandSkills` 内多个指挥战法先后改速：`triggerCommandSkills`（`action.ts:1088`）
  内部 `for (const id of unit.general.commandSkillIds)`（`action.ts:1091`）循环施加该单位**全部**指挥战法；
  重排在它返回后（`combat.ts:197` 之后）执行一次，速度变化已全部结算，不会漏。
- 排除项：缓师徐持 `speed_buff` −20（`skills.ts:3664`）虽是一类指挥 prep，但走 `onHurt`（`skills.ts:3650-3658`），
  prep 阶段只登记不结算（`action.ts:1279` 排除 `onHurt` 战法的 `output`），不参与准备阶段出手顺序。
