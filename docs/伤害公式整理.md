# 伤害公式整理（攻击伤害 / 谋略伤害）

> 单一真源：`src/engine/formulas.ts`（`calcDamage` 及其因子函数）+ `src/engine/action.ts`（增减伤 / 无视属性的组装点）。
> 调研依据：`dateyuan/战斗伤害公式调研.md`、`dateyuan/谋略战法受谋略成长调研.md`。
> 本文每一个数字都可用 `calcDamage` 直接复算，无一为估计值。

---

## 0. 一句话总览

两种伤害**同构**：都是三段相加，差别只在第二段的属性系数、第三段的属性因子，以及谋略伤害率要先被施法者谋略缩放。

```
攻击伤害 = 兵力基础(攻击曲线)  +  攻击 × r × 伤害率 × M        +  单位伤害 × 伤害率 × F(攻−防) × M
谋略伤害 = 兵力基础(谋略曲线)  +  谋略 × 0.5 × S(目标谋略) × M  +  单位伤害 × 有效伤害率 × S(目标谋略) × M
```

- `r`：攻击基础随机系数 ∈ {0.30 … 0.39}（**普通攻击伤害唯一的随机来源**；物理 DoT 固定 0.4）
- `M`：增减伤因子 = `max(0.1, 1 + Σ造成侧增伤 + Σ受到侧增伤 − Σ减伤)`（单一总和，攻击/谋略统一）
- `F(攻−防)`：攻防差曲线；`S(目标谋略)`：目标谋略减伤阶梯
- **兵力基础不吃 `M`**（三段里唯一不吃增减伤的部分），也不吃伤害率

三处最容易记错的结构差异：

| 结构差异 | 攻击伤害 | 谋略伤害 |
|---|---|---|
| 第二段（属性基础） | 乘伤害率、带随机 | **不乘伤害率**、无随机、乘 `S` |
| 第三段属性因子 | 攻防差 `F` | 目标谋略 `S` |
| 伤害率是否被属性缩放 | 一般不被缩放（例外见 §2.4） | 「受谋略影响」的段一律先缩放 |

## 1. 公共件

### 1.1 兵力基础伤害（与伤害率、增减伤都无关）

```
攻击：round( 373 × 兵 / (7700 + 兵) )        // 10000 兵 ≈ 211
谋略：round( 178 × 兵 / (6459 + 兵) )        // 10000 兵 ≈ 108（攻击的约一半）
```

| 兵力 | 1000 | 3500 | 5000 | 7000 | 9000 | 10000 | 20000 |
|---|---|---|---|---|---|---|---|
| 攻击曲线 | 43 | 117 | 147 | 178 | 201 | 211 | 269 |
| 谋略曲线 | 24 | 63 | 78 | 93 | 104 | 108 | 135 |

DoT（妖术 / 燃烧 / 恐慌 / 诅咒 / 引燃 / 动摇）的兵力基础 **× 1/3**。

### 1.2 单位伤害曲线（攻击 / 谋略共用）

```
单位伤害 = 300 × 兵 / (3500 + 兵)     // 9000 兵 = 216，10000 兵 ≈ 222.2
```

| 兵力 | 1000 | 3500 | 5000 | 7000 | 9000 | 10000 | 20000 |
|---|---|---|---|---|---|---|---|
| 单位伤害 | 66.7 | 150 | 176.5 | 200 | 216 | 222.2 | 255.3 |

曲线刻意「低于 3500 增长快、高于 7000 明显变慢、有上界（→300）」，这是兵力既影响第一段又影响第三段的第二条路径。

### 1.3 增减伤因子 M

```
M = max( 0.1, 1 + Σcaused + Σtaken − Σreduce )

Σcaused = 施法者身上 damage_boost(direction=caused) 的 rate 之和   （大赏三军、神兵…）
Σtaken  = 受击者身上 damage_boost(direction=taken)  的 rate 之和   （神兵天降…）
Σreduce = 受击者 damage_reduce 之和 + 兵种克制 + 宝物/特性/避锐等
```

四条硬口径：

1. **全加算，不乘算**。增 60% 与减 60% 精确抵消 → `M = 1`（不是 1.6 × 0.4）。
2. **10% 是唯一地板**。总和低于 −90% 一律压到 `0.1`。
3. **兵种克制并入加算**，不是独立乘区：被克制方打克制方 `Σreduce += 0.3`；`+30% 增伤 − 30% 克制 = M 1.0`，而独立乘算会得 0.91。长枪兵改写可给出 **−0.3（负减伤 = 增伤）**，同样在这个池子里相抵。
4. **「大幅度降低 / 大幅减伤」写的是哨兵值 1000%（`HUGE_MODIFIER_RATE = 10`）**，不是 90%。90% 会被对方增伤抵掉（对方 +200% 时仍挨 210% 伤害）；1000% 配合 10% 地板才是「无论对方增伤多高都只吃 10%」。

### 1.4 取整与截断链路

```
三部分各自 Math.round → 相加 → max(1, round) → min(结果, 目标当前兵力)
```

- 伤害率 / 恢复率用 `roundRate`：**1% 粒度「八舍九入」**（小数 ≥ 0.9 进位，否则舍去）。
- 单次伤害不超过目标当前兵力；**伤害与目标兵力无关**（除这条截断）。
- **士气不进伤害**：`moraleRate` 只乘发动率 / 生效几率（每点士气 +0.6%），伤害公式里没有任何士气项。

## 2. 攻击伤害

### 2.1 三部分

```
兵力基础 = round( 373 × 兵 / (7700 + 兵) )                          ← 不吃 M
攻击基础 = 攻击 × r × (伤害率/100) × M                                ← 无视目标防御
主要伤害 = 单位伤害(兵) × (伤害率/100) × F(攻击 − 目标防御) × M
总伤害   = 三段各 round 后相加，再取 max(1, ·)、截断到目标兵力
```

`r` 的取值：普通攻击 / 攻击战法从 `{0.30, 0.31, …, 0.39}` 均匀取一个（同一武将连续两次普攻因此天然波动约 30%）；**物理 DoT（动摇）固定 0.4，无随机**。

### 2.2 攻防差曲线 F

```
攻防差 ≥ 0：F = 3 − 500/(250 + diff)      // diff=0 → 1.00，趋近 3（有上界）
攻防差 < 0：F = 100/(100 − diff)          // diff=−100 → 0.50，趋近 0
结果保留两位小数
```

| 攻防差 | −100 | −70 | −50 | 0 | 50 | 100 | 130 | 200 | 250 | 500 | 1000 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| F | 0.50 | 0.59 | 0.67 | 1.00 | 1.33 | 1.57 | 1.68 | 1.89 | 2.00 | 2.33 | 2.60 |

高收益区间在 **−70 ~ 130**，区间外边际递减且双向有界：攻击再高也到不了 3 倍，防御再高也压不到 0（>0）。

### 2.3 无视防御

`目标防御 = 目标防御 × (1 − Σignore_def)`，只统计 `damageType` 缺省为 `physical` 的那一轨（策略轨另算，见 §3.4）。比例钳制在 [0, 1]。

### 2.4 攻击伤害的伤害率何时会被属性缩放

缺省不被缩放。例外是文案写了「受某属性影响」的攻击段，机制与谋略同构：`roundRate(scaledValue(rate, 成长率, 生效属性))`（如令明负榇受速度、鹤翼分兵受谋略、部分段受防御）。

## 3. 谋略伤害

### 3.1 三部分

```
兵力基础 = round( 178 × 兵 / (6459 + 兵) )                            ← 不吃 M
谋略基础 = 谋略 × 0.5 × S(目标谋略) × M                                ← 不乘伤害率、无随机
主要伤害 = 单位伤害(兵) × (有效伤害率/100) × S(目标谋略) × M
总伤害   = 三段各 round 后相加，再取 max(1, ·)、截断到目标兵力
```

### 3.2 有效伤害率（受谋略缩放）

战法描述里的数字 = **谋略 80** 时的值：

```
谋略 ≥ 80：有效伤害率 = roundRate( round(基础值 + 成长率 × (谋略 − 80)) )
谋略 < 80：有效伤害率 = roundRate( 基础值×0.4 + 基础值×0.6×(谋略/80) )
```

- 例：基础 194% / 成长 1.925 → 谋略 200 时 `194 + 1.925×120 = 425`。
- 缩放只发生在**进入公式之前**；一旦主要伤害算出，与施法者谋略再无直接关系。
- 成长率是隐藏参数，来源见 `docs/成长率反推规律速查.md` 与 `dateyuan/谋略战法受谋略成长调研.md`。

### 3.3 目标谋略减伤 S

**只看目标谋略，与双方谋略差无关**（最常见的误区）：

```
目标谋略 ≤ 50：S = 1（无减伤）
目标谋略 > 50：S = max(0.1, ceil(100 − (75 − 9375/(75 + 目标谋略))) / 100)
```

| 目标谋略 | 50 | 52 | 80 | 100 | 109 | 129 | 150 | 200 | 300 | 999 |
|---|---|---|---|---|---|---|---|---|---|---|
| S | 1.00 | 0.99 | 0.86 | 0.79 | 0.76 | 0.71 | 0.67 | 0.60 | 0.50 | 0.34 |

单调递减、饱和递减；因 `ceil` 向上取整，**实测下界是 0.26**（目标谋略取 1e9 得 0.26）—— 谋略再高也最多减约 74%，伤害不会归零。52~109 区间降幅最猛，>129 后边际很小 —— 实战「堆到约 109 性价比最高」的由来。

### 3.4 无视谋略

`目标谋略 = 目标谋略 × (1 − Σignore_def[damageType=strategy])`，在进 `S` 之前折减。与物理轨互不影响。

### 3.5 谋略 DoT 的三处差异

| 项 | 普通谋略 | 谋略 DoT（燃烧/恐慌/妖术/诅咒/引燃） |
|---|---|---|
| 兵力基础 | × 1 | × 1/3 |
| 谋略基础系数 | 0.5 | **0.25** |
| 主要伤害 | 不变 | 不变（同一条公式） |

> 动摇是**攻击**伤害的 DoT：兵力基础 ×1/3、攻击基础固定 0.4、主要伤害走攻防差曲线，不触发谋略轨的一切。

DoT 还有一条独立口径：**每次跳伤在「挂上时」冻结**（按挂上时的施法者兵力、双方属性、增减伤合计算好），之后施法者兵力下降、增伤到期都不再影响已冻结的跳伤。

## 4. 逐因子对照表

| 因子 | 攻击伤害 | 谋略伤害 |
|---|---|---|
| 兵力基础 | `373b/(7700+b)`，DoT ×1/3 | `178b/(6459+b)`，DoT ×1/3 |
| 属性基础 | `攻击 × r × 伤害率` | `谋略 × 0.5`（DoT 0.25），不乘伤害率 |
| 随机 | 0.30~0.39 均匀（唯一随机源） | 无 |
| 属性因子 | 攻防差曲线 F | 目标谋略阶梯 S |
| 伤害率缩放 | 一般无（例外 §2.4） | 受谋略影响的一律缩放 |
| 增减伤 M | 吃 | 吃（同一套单一总和） |
| 兵种克制 | 吃（并入 Σreduce） | 吃（并入 Σreduce） |
| 无视属性 | 无视防御 % | 无视谋略 %（独立轨） |
| 士气 | 不进伤害 | 不进伤害 |

## 5. 算例

### 例 A：普攻（含兵种克制与增伤的抵消）

骑兵、攻击 200、兵力 9000、伤害率 100%，打防御 100 的弓兵；骑兵身上有「造成伤害提高 30%」，但弓兵克制骑兵（`+0.3` 减伤）。

```
Σ增伤 0.3 − Σ减伤 0.3 → M = 1.00          （加算相抵，不是 1.3×0.7=0.91）
兵力基础 = round(373×9000/16700) = 201     （不吃 M）
攻击基础 = 200 × r(0.30~0.39) × 1 × 1 = 60~78
主要伤害 = 216 × 1 × F(200−100 = 1.57) = 339
总伤害   = 201 + (60~78) + 339 = 600 ~ 618
```

### 例 B：谋略战法（受谋略缩放 + 目标谋略减伤）

施法者谋略 200、兵力 9000、无增减伤；战法基础 100%、成长 0.7%/点；目标谋略 100。

```
有效伤害率 = 100 + 0.7×120 = 184（1% 粒度八舍九入）
S(100)     = 0.79
兵力基础 = round(178×9000/15359)    = 104  （不吃 M）
谋略基础 = 200 × 0.5 × 0.79          = 79
主要伤害 = 216 × 1.84 × 0.79         = 314
总伤害   = 104 + 79 + 314 = 497
```

对照：同一战法打谋略 50 的目标，`S = 1` → `104 + 100 + 397 = 601`，**仅目标谋略一项就是 −17%**。

## 6. 引擎落点与未建模项

| 环节 | 落点 |
|---|---|
| 三段计算 | `formulas.ts` `calcDamage`（攻击 / 谋略两支） |
| 兵力基础 / 单位伤害 | `troopBaseDamage` / `unitDamage` |
| 攻防差 / 目标谋略 | `attrFactor` / `targetStratMitigation` |
| 增减伤总和 | `buffMult`（+ `action.ts` 的 `damageBoosts` / `sumReduce`） |
| 兵种克制 | `troopCounterReduce` → `action.ts` `troopCounterReduceOf`（含二级兵种改写） |
| 无视属性 | `applyIgnoreDef` + `physicalTargetDefense` / `strategyTargetStrategy` |
| 伤害率缩放 | `scaledValue` + `roundRate`（调用点在 `action.ts` 各输出段） |
| 截断 | `applyTroopCap` |

复算入口：`npx tsx scripts/_damage_formula_dump.mts` —— 直接调真函数打印本文四张表与两个算例，改公式或改文案后跑一次即可对齐。

**未建模 / 已决策的偏差**（写在这里是为了避免下次重复考古）：

1. **策略伤害的「增伤保护下限」特殊规则不建模**：官方承认的历史缺陷（受到侧减伤不能完全抵消造成侧增伤），2022-05-11 只修了一半、精确数学形式从未公布，社区模拟器也没实现。引擎统一用单一总和模型。
2. **没有「攻击伤害宏观 ±5% 波动」**：旧调研曾加，2022 权威原文只承认攻击基础的 0.30~0.39 随机，已删除。
3. **恢复提高效果按 1**（宝物【抖擞】/锻造【仁心】未建模），恢复值另见调研 §四。
4. **士气只作用于发动率**，不作用于伤害 —— 想让「高士气打得疼」需要走增伤状态，不能指望士气系数。

## 7. 常见误区速查

1. 伤害率翻倍 ≠ 总伤翻倍（兵力基础不随伤害率变，200% 战法 < 2× 普攻）。
2. 谋略伤害**不看双方谋略差**，只看目标谋略的绝对值阶梯。
3. 减伤 90% 与「大幅减伤」不是一回事：后者是 1000% 哨兵 → 触及 10% 地板。
4. 兵种克制不是独立乘区，能被增伤按 1:1 抵掉（0.91 vs 1.00 的差别）。
5. 兵力基础三段中的第一段不吃增减伤 —— 把减伤堆到 100% 也挡不住它。
6. 士气高 ≠ 伤害高，只等于更容易发动。
