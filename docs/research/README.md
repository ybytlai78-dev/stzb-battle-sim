# 未实现主战法武将调研（45 位）· 数据总表

> 数据文件：[`heroes-research-merged.json`](./heroes-research-merged.json)（45 位武将原样合并，含 `batch` 字段）
> 分批次原始文件：`heroes-batch-1.json` … `heroes-batch-5.json`

## 背景

本仓库按 `docs/下架武将清单.md` §1.2「补 1 个机制」推进武将主战法实现。清单中「**需先调研**」档共 **45 位**武将——
主战法尚未实现、且仓库现有调研文档（`dateyuan/通用战法调研.md` / `dateyuan/武将数据调研.md`）没有覆盖其主战法全文与官方数值。
本次调研即补齐这 45 位的主战法官方字段与画像资源，结果合并为上述 JSON 与本文总表。

## 来源与通道

- **官方移动版技能库（直连，主通道）**：`https://stzb.163.com/m/skilllist/{id}.html`——服务端渲染，`curl.exe` 直接可抓，45 个主战法全部命中。
- **官方移动版武将库**：`https://stzb.163.com/m/herolist/{heroId}.html`——面板/成长/兵种/阵营/立绘交叉核对。
- **官方桌面版技能页**：`https://stzb.163.com/jinenglist/{id}.html`——批次 4 / 5 与移动版对照（陈宫的版本冲突即由此发现）。
- **仓库官方快照（离线交叉核对）**：`scripts/skill_extra.json`（642 条）、`scripts/_official_hero.json`、`scripts/hero_extra.json`、`web/data/heroes.json`、`web/data/portrait_map.json`、`web/data/portraits.json`、`dateyuan/hero_growth_verified.json`。
- **立绘 CDN**：官方 `stzb.res.netease.com/.../watermark/card_{iconId}.jpg`；404 时回退社区镜像 `g0.gph.netease.com/.../card_medium_{iconId}.jpg`（裴秀 100801、XP献帝 100795、XP马良 100792、刘备 100803 走回退）。
- **社区来源（仅作参考，一律不采信为数值）**：九游、17173、清风手游网、光环助手、newton.com.tw、vipcn 等，用于核实歧义方向；低可信度推定已在 `notes` 中标注。
- **`r.jina.ai` 不可用**：返回 `401 AuthenticationRequiredError`——`blocked ... bad network reputation (AS30058)`，故未采用该代理通道。
- **1 级描述来源**：官方技能页只发布满级文本；`descLevel1` 取自 `scripts/skill_extra.json`（官方客户端数据副本，数值符合满级值减半的 10 级线性规律）。

### 生成命令

本轮由 agent **并行调研**（每个批次一个 agent 独立抓取 + 交叉核对），**无脚本**：

```text
批次 1-5 并行：curl.exe 直连 stzb.163.com/m/skilllist 与 /m/herolist
  → 与 scripts/*.json 官方快照逐字段交叉核对
  → 输出 docs/research/heroes-batch-{1..5}.json
合并（本轮一次性拼接）：5 个 heroes[] 原样拼接 + 来源 URL 去重 + 计数
  → docs/research/heroes-research-merged.json
```

> 合并脚本为一次性临时脚本，未入库（约束：只新增合并 JSON 与本文）。

### 重新抓取 / 核对提示

1. **单条复核**：直接开官方页 `https://stzb.163.com/m/skilllist/{officialId}.html`（上文总表第 4 列即 `officialId`），与 JSON 内 `mainSkill.descMax` 逐字比对。
2. **不要用 `r.jina.ai`**（401 风控）；用 `curl.exe` 直连，桌面版页面是 JS 渲染、抓不到正文，只有移动版 `/m/` 是服务端渲染。
3. **「两版本拼接」**：官方多段描述有首尾相连的重复瑕疵（本批 **8 位**经查涉及：兀突骨 / 华雄 / 孙坚 / 张郃 / 徐晃 / 诸葛亮 / 高顺 / XP献帝），仓库统一按 `clean_hero_descs.mjs` 口径取前半段；重新抓取后**不要**自行合并两版，差异已在「待拍板」清单列出。
4. **置信度 `medium` 的 12 位**（见总表 `confidence` 字段）优先级最高——多数是口径冲突或官方无数值，重新抓取未必能解决，需用户拍板。
5. **画像**：`portrait.alreadyInRepo` 全 45 位均为 `true`（主图在库）；4 位（SP赵云 / SP卢植 / SP太史慈 / SP蔡文姬）缺 `_s` 小头像。
6. **数值自检**：`node -e "JSON.parse(require('fs').readFileSync('docs/research/heroes-research-merged.json','utf8'))"`（必须通过）。
