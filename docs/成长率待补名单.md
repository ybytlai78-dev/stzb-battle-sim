```bash

# 2) 反解（先跑工具，别手算）
node scripts/derive_growth_rate.mjs --base <基值@属性80> --points "属性:实读,属性:实读"
# 3) 合理性检验：交集宽度 / 翻倍阈值量级 / 线性
# 4) 入库：skills.ts 填 growthRate → listing.ts 摘名单 → 实测锁定用例 → tsc + npm test
```
