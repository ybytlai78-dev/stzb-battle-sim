## 0. 口径

- **本报告只算伤害期望**：胜率 / 平局 / 兵力优势是 L4（`battle-sim.html`）的事，这里不掺。
- **靶子 = 不还手的木桩 ×3**：不放战法、不普攻（引擎 `BattleConfig.inertSides`），只挨打；属性 = 不还手木桩 ×3（防 150 / 谋 100 / 兵力 150000）；我方打在木桩身上的 DoT / 延迟伤害照常结算。
- **三阶段**：① 逐将粗筛 = 每个候选战法 **3 场**（**双槽将按成对组合评估**：单挂前 10 名当搭子基准、与全部候选各配一次——击势这类"要带满槽才见效"的增伤战法不会被单挂成绩误杀）→ 每将保留前 32 个选项；② 组合粗筛榜单 = 整队组合各 **3 场** → 前 32 支进决赛；③ 决赛 = 每支 **20 场**（下限 20）→ 汇总伤害期望排行。
- **只填空槽**：已指定战法的槽位原样保留、不进候选池（守全队战法唯一）；候选池 = 全部可学战法 − 队内已占用。
- **排序口径 = 核心将「陆抗」的伤害期望**（可多选核心 → 求和），**不是全队总伤**：辅助战法的强度不随施法者属性变（实测「计险远近」放谁都是 44,699）→ 用总伤排时大量并列、搜索随手挑一个，就会出现「主C带辅助、辅助带输出」；改成核心将口径后，输出战法只有放在核心将身上才涨目标，定位自然落位。全队总伤只作参考列。
- **参与匹配的将**：陆抗（其余将的战法原样保留、不参与搜索，对齐 L3 优化器的 `unitIdxs`）。
- **复现**：种子 = 基种子 20260922 + 场次（同一场次对所有候选一致 → 配对比较），奇数场交换场地；木桩方视角随交换场地翻转。
