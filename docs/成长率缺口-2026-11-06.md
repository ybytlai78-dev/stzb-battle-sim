- 垒实迎击 `onHurt[0].output[0]` 恢复 200：包内 `200900` 链没有非零 intel，属固定值；`strategyScaled: true` + `growthRate: 0` 只是无效标记。

- 皇裔流离：`healGrowthRate: 0.6` 已接线。

## 为什么当时“0 缺口”不可信（保留审计依据）

- `tests/growth_rate_audit.test.ts` 与 `scripts/_audit_scaled_no_growth.mts` 只判 `growthRate !== undefined`，
  因此 `growthRate: 0` 会被当成“已挂载”。全树正向扫描暴露了 18 条零/缺段，其中 15 条是真缺口（上表）。
- `npm run rag:slots -- --only-diff` 只覆盖 162 个战法 / 466 个槽中的 276 个（59.2%），另有 190 个槽未覆盖；
  且槽映射不覆盖 `delayedOutput`、`recipientDamageByHigherStat` 等特殊字段，不能据此证明全库无缺口。
- `docs/成长率待补名单.md` 顶部“双向归零”是 2026-10-24 的历史快照，§二/§三 的明细仍是旧名单，不要直接引用为当前结论。
