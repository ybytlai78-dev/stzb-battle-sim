# 武将详情页 · 全屏改版（2026-11-07）

> 目标：把仓库 `web/` 的武将详情页改成游戏内那种「左大图铺满 + 右数据面板」的全屏版式。
> 用户口径（两次）：`m01981`「可以先走第一条路，武将详情铺满页面」；`m02064`「1.一部分武将没有铺满…2.宝物移动到战法栏右边…3.没有全覆盖屏幕，我要的是全覆盖，顶栏取消，的配点，兵种等选项下移」。

## 二、实现（三处改动）

1. `web/heroes.ts`
   - `import bigArtJson from './data/big_art.json'`
   - `export const BIG_ART: Record<string, number>`
   - `export function bigArtSrc(heroId: string): string` —— 有登记才返回 `/portraits_big/{heroId}.webp`（走 `asset()` 前缀），否则空串。
2. `web/teamEditor.ts`（`openHeroDetail`）
   - 遮罩加全屏类：`mask.className = 'modal-mask page-mask hero-detail-full'`。
   - 宝物从左侧移到战法栏第 4 格：`<div class="skills-row">${mainSkillEl}${equips}${hdTreasureSlotHtml()}</div>`。
   - `hdSideHtml()` 只输出大图层：`.hd-stage.has-big|no-big > .hd-bigfill + .hd-bigart + .hd-veil + .hd-side-labels`（势力 / 竖排名字 / 竖排星级）。
3. `web/styles.css`（本轮末尾整块重写）
   - `.hero-detail-full .hero-detail-modal { width:100vw; height:100dvh; border:0; border-radius:0 }` —— 真正全屏。
   - `.m-head`：绝对定位右栏顶部、标题隐藏，只留 详情/配点/兵种/方案 页签 + 关闭。
   - `.hd-bigart`：`background-size:auto 100%; background-position:18% bottom` —— 大图按高度铺满、贴底、偏左；透明边缘由 `.hd-bigfill`（同图放大 4% + `blur(36px) brightness(.30)`）作环境底。
   - `.hd-veil`：横向渐变在 54% 处压黑；右侧面板 `.hd-main { background:#080706 }` 实色，边界干净。
   - `.hd-main`：`width:min(46vw,680px)`、flex 纵向居中、纵向可滚。
   - `.skills-row > * { flex:1 1 0 }` —— 三战法 + 宝物四等分。
   - `.hd-level-row` 不许换行（1024 宽时「等级」被折成两行的问题）。
   - `@media (max-width:980px)`：大图占上 36%、面板占下 64%、面板实色 + `::before` 顶部渐隐条。

## 六、场景大卡背景（2026-11-08 补）

   `/sdcard/Android/data/com.netease.stzb.netease/files/netease/stzb/Documents/mini_client_res/card/card_big/`

## 七、右栏浅灰底（2026-11-08）

用户口径：「右边背景不要纯黑色，用浅灰色」。

做法不是逐个改颜色，而是**在 `.hero-detail-full .hero-detail-modal` 作用域内重定义主题变量**（`--panel/--panel-2/--line/--ink/--text/--text-dim/--gold/--gold-bright/--red-soft/--blue-soft`），整块右栏（属性卡、战法卡、页签、底栏按钮）一次性翻转为深字浅底；全局暗色主题（其它页面）完全不受影响。

- 面板：`--panel: #e9e6e0`，`.hd-main` 用 `linear-gradient(90deg, rgba(233,230,224,0), #e9e6e0 15%)` 与大图柔和衔接。
- 蒙层 `.hd-veil` 由「压黑」改成「白色雾化」，否则暗蒙与浅底交界会出现一道脏灰色的边。
- 仍写死暗底的局部元素逐个翻亮：`.hd-treasure`（宝物卡）、`.hd-treasure .ts-img`、`.hd-cs`（陈寿特性槽，含 filled 态渐层）与 `.cs-flag`。
- 左缘竖排标签（势力/名字/星级）在图上，必须保持浅色：`.hd-side-name #fff6e2`、`.hd-stars #f0c860`，并在 `.hd-side-labels::before` 加大暗色渐隐幕（横竖屏都有），否则白字压在白云上不可读。
- 窄屏同样走浅底（`.hd-main{background:#e9e6e0}` + 顶部渐隐条改浅）。

验证：`tsc` exit 0；全量 **156 files / 1473 tests** 全绿；1440×900 实拍 `h16`/`h451`/`h102002`（无场景大卡回退）+ 430×900 竖屏，均目视通过。

> 排查备注：小图上「刘备」二字看上去是暗金色，一度以为渲染错误；放大到像素级后确认是浅色字 + 重阴影在缩略下的视觉错觉（`getComputedStyle` 也是 `rgb(244,232,204)`），不是 bug。

### 七-补：色阶定稿（同日第二轮）

第一版用了 `#e9e6e0`，用户反馈「有点太白太亮，不能突兀也不要抢眼」。最终定稿为**中性暖灰**，靠三个令牌定调：

| 令牌 | 值 | 说明 |
|---|---|---|
| `--panel` | `#5a5650` | 右栏底（实际像素已核：`(90,86,80)`） |
| `--panel-2` | `#66625a` | 属性卡 / 战法卡底，只比面板亮一档 |
| `--text` / `--ink` | `#f2eee6` / `#f5f1e9` | 主文字，对面板对比度 ≈ 6.9:1 |
| `--text-dim` | `#d6d0c3` | 次要文字（可学习 / 加成括号） |
| `--green` | `#a9c894` | 携带兵力的公式注释（原本是暗绿，在灰底上几乎看不见） |

配套：蒙层 `.hd-veil` 与底栏渐变同色（`rgba(90,86,80,·)`），因此大图到面板是「渐渐透气」而非一条硬边；宝物卡 / 陈寿特性槽同步换成 `#66625a` 与 `rgba(255,255,255,.07)`。

教训：深色主题里做「浅色面板」不是把底色提亮就行——`--green`、`#0d0b09` 这类**没走变量**的写死色会变成隐形字，必须一并扫一遍（本轮扫出 6 处）。

### 七-补二：定稿为「游戏内同款深色半透明」（同日第三轮）

用户发来游戏内张辽详情页截图：「差不多游戏内这种颜色」。取样确认游戏面板不是实色，而是**大图通铺全屏 + 右侧压一层半透明暗色**（面板区像素随背后画面变化，中位约 `(60,59,64)`）。

落地：

- `.hd-scene` 由「只占左侧 66%」改为 `inset:0`（**全屏铺满**），`background-position: 34% 18%` 把人物放在偏左；
- `.hd-main` 不再实色，改为 `linear-gradient(90deg, rgba(18,18,22,.34) 5%, .78 14%, .89 26%, .90 100%)` —— 大图从面板下透出来；
- `.hd-veil` 同步改成只在右半加暗（左半完全透明），否则左侧大图也会被压灰；
- 主题变量回到浅字：`--ink #efe9dc`、`--text #e8e2d5`、`--text-dim #a9a49a`、`--gold #cbbd90`、`--green #9fbf86`；卡片底 `--panel #1e1f24`、`--panel-2 #26272d`。
- 底栏渐变改成 `rgba(18,18,22,.92)`，与面板同源。

教训（给下一次改色）：这面板的颜色不能靠「调 `--panel` 一个值」完成——**透明度、铺图范围、蒙层方向**是一组联动的量；只改底色会得到“要么死黑一片、要么白得发光”两种极端，中间态必须靠多层半透明叠出来。

### 七-补三：立绘不裁切 + 交界渐变（同日第四轮）

用户反馈两点：①「还是按原来的立绘比例，现在的立绘不能全部展示了，被截掉了一部分」；②「背景图片和右边栏目的交界处采用渐变的方式」。

根因：上一轮用 `background-size: cover`（保证铺满，但**必然裁边**）。场景大卡是 1008×1008 方图，进 1440×900 视口时上下被裁掉约 37%。

改法（两层）：

- `.hd-scene` 改 `background-size: contain` + `background-position: left center` —— **整张图完整显示**（高度撑满、宽度 = 视口高），右缘不再丢画面；
- 右侧剩余空间交给新增的 `.hd-scene-fill`（同一张图 `cover` + `blur(56px) brightness(.32)` + `scale(1.14)`），负责铺底，避免出现纯黑竖条。

交界渐变用的是**按实际图边计算的遮罩**，不是固定百分比：

```css
mask-image: linear-gradient(90deg,
  #000 0,
  #000 calc(min(100vw, 100vh) - 320px),
  transparent calc(min(100vw, 100vh)));
```

`contain` 的方图右边界恰好等于 `min(100vw, 100vh)`，所以提前 320px 开始化开、到边界恰好透明 —— 1440×900 与 1920×1080 两种视口下都没有硬线（两者图边分别落在 900 / 1080，固定百分比写法会在宽屏漏出竖线，这是上一版的问题）。窄屏改垂直方向遮罩（`180deg`，62%→96%）。

验证：1440×900（刘备/关羽）、1920×1080（刘备）实拍确认无裁切、无横竖硬边；`tsc` 0，全量 1473 测试全绿。
