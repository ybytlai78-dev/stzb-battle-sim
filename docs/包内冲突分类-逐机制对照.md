### 伤害乘区（造成/受到/减伤）共 **51** 条机制

### 引擎冲突键的粒度（读表前必看）

- 域：`sourceSkillType`（主动/指挥/被动/追击）——**跨战法类型一律各自入栈**；
- 同类型内：`damage_boost` / `damage_reduce` 再按「过滤维」细分（`damageKind` / `skillTypes` / `dotTypes` / `skillIds` / `attackOnly` / `charges`…，`sameDamageBoostFilter`），
  即【攻击伤害提高】与【主动战法伤害提高】是两条独立轨，互不取较高（用户 2026-09-16 口径）；
- `trigger_boost`（发动率/生效几率）在同类型内取较高、跨类型**逐条相加**（`action.ts:522` 注释）。

这三池是伤害公式里**唯一的加算区**（`mult = clamp(1 + Σcaused + Σtaken − Σreduce, 0.1)`），
包内对它们全部标 `2`（效果不叠加·数值档）——即**同类只保留一份（取较高）**，引擎现状是
「同类型取较高、跨战法类型进同一池累加」。差异只在跨类型，量级 = 两条来源之和。
