# 待补充机制清点（Skipped 通用战法）

本文件是 **199 个可学习通用战法中 skipped 战法**的机制清点（当前 **26** 个）。**用户 2026-09-19 口径：C/D 级战法不再实现（10 个，遇到即跳过）**，剩 **16 个 A/B/S 待机制落地**。每个战法因需要引擎缺失机制而暂缓录入（未实现不算遗漏，算**待机制**）。受属性缩放未确认的，只打标签、本轮不录入。

**目的**：机制补全后，可依本文件立即可开始实现。建议顺序 = 受益战法最多的机制优先。

**联动**：数据库 `skills` 表 `missing_mechanics` 列（自然语言描述）+ `mechanism_key` 列（稳定键）。机制实现后，用 `SELECT * FROM skills WHERE status='skipped' AND mechanism_key='<键>'` 立即捞出该机制下的全部战法。

## 二、引擎现状核对（2026-08-04）

**已实现**（从"缺失"清单剔除）：
- **士气发动率系数**（`formulas.ts` `moraleRate` + `action.ts` `moraleTriggerRate`）：士气 100→系数1，120→1.12，80→0.88，作用于带发动率属性的所有战法。**但仅影响发动率**——`士气比较`（目标士气 vs 自身）与`士气降低`（及锋而试 目标士气-10）仍是缺失机制。
- **受击触发（onHurt p1，2026-09-15）**：`onHurt` 已支持 `damageSource:'basic'` / `timing:'before_damage'` / `victim:'locked'` / `thisHitReduce` / `counter` 状态 / 被动 `endRound` / `roundStartRepeat` 窗口。空城、回马、攻其不备、健卒不殆、反击之策已入库。
- **兵种过滤 / 普攻主动分流已入库**（2026-09-15 p2）：`teamTroopFilter`、输出 `troopTypes`、`damage_boost` 的 `damageSource`/`skillTypes`/`damageType`、`split.charges`、`oddRounds`、代打 `attacker:'recipient'`。方圆、疏数、衡轭、锋矢、鱼鳞、鹤翼、白刃、全军突击、飒沓如星已入库。
- **围困 / 妖术 / 燃烧 / 恐慌 DoT / 分兵 / 挑衅 / 先手**（priorityRounds 仅指挥战法）已有状态类型与测试。
- **击势 / 兵无常势**（2026-08-25）：`ignore_def` 作用于攻击攻防差的目标防御；`random_pick` 每回合不放回抽 N 组效果；被动输出级 `chance` 独立判定。
- **穷追猛打 / 激昂 / 疾击其后 / 扬威**（2026-09-15）：现有机制可做、无受谋略，已入库。`roundRepeat.startRound`、被动 `chance`、追击两段独立 `random_single`+区间率、`charges:1` 下一次增伤均已验证。
- **援军之策**：同援军秘策（休整 + `startRound:5`），只差受谋略成长率 → `pending_strategy_scale`，下次做，不取基值硬做。
- **attackScaled / taken 受击消耗 charges / `decayFifths` / 被动 `selfPhysBoost` 已入库**（2026-09-16 p3）。万箭齐发、文伐、不攻、恃强淬锋已入库。
- **距离 +1 前四张 + 特殊目标选择全部 6 张已入库**（2026-09-19 p4，10 个）：远攻秘策、远攻之策、远攻奇略、远攻强化（`range_buff` 攻击距离，机制已有）；近攻（新增显式 `nearest` 模式 = 有效距离内最近）、远射 / 连环段1（`farthest`）、兼弱攻昧、始计、铁戟金戈。新增引擎能力：`farthest` / `nearest` 目标模式；伤害段 `targetPick:'lowest_defense_in_range' / 'lowest_strategy_in_range'`（`unitsInSkillRange` + 生效属性比较）；`inflict_status.targetPick:'highest_troops_enemy'`；铁戟金戈用 `random_pick count:1` 实现「每次释放 50/50 抽 2 目标 330% / 3 目标 225%」。受谋略缩放段（连环 132/198、兼弱攻昧 159、始计 20%/30%）`growthRate` 留空，已登记《成长率待补名单》§三。合纵连横（4 项新机制）后置。
- **士气组 5 张已入库**（2026-09-19 p5）：望风而降、激水之疾、蓄盈待竭、胜负先征、及锋而试。新增引擎能力：① `morale_branch.compareTo:'caster'`（目标与施法者**相对**士气比较：严格低于走 low、不低于（含相等）走 high——低于是严格小于，用户确认）；② 主动战法输出级 `chance` 生效（原仅被动/指挥；几率类一律吃士气加成，用户口径）；③ `BaseSkill.damageRatePerCast`（每次发动后伤害率递增，不封顶、走 `skillCastCounters`）。胜负先征复用 `morale_branch by:'caster'`（阈值 100）+ `grant_first_aid`；及锋而试士气 −10 复用 `morale_boost` 负值。受谋略缩放段（望风而降 108%×2/恐慌 98、激水之疾 180%/谋略−20、胜负先征 恢复 75%）`growthRate` 留空（DoT/急救必填字段给 0），已登记《成长率待补名单》§三。
- **受击链路收尾 5 张已入库**（2026-09-19 p6）：垒实迎击、百战无怯、疾风迅雷、反击（战法 id `fanji_counter`，避免与既有「反计」`fanji` 冲突）、诱敌深入。新增引擎能力：① `remove_by_source_skill_type.debuffsOnly`（只移除负面，垒实迎击；辞后定朝口径仍为有害+有益都移除）；② `BaseSkill.onBasicHit`（普攻**命中并实际结算后**按几率执行 output，`dealAttack` 接线；疾风迅雷仅自身普攻、第 3 回合起）；③ `PassiveSkill.stacksReduceHeal`（层数体系：开局满层挂 `damage_reduce`、造成伤害 +1、回合开始/受击 −1 且**掉层才回血**——0 层不掉不回血，用户确认）。垒实迎击三段受击各 50% 独立判定（用户确认）；诱敌深入「每回合首次」= 每名友军各一次（用户确认）；反击「持续 2 回合」= duration 3（覆盖后续两个完整行动回合，用户确认）。受谋略缩放段（垒实迎击恢复 200%、百战无怯恢复 200%、诱敌深入 136%）`growthRate` 留空（heal 必填给 0），已登记《成长率待补名单》§三。
- **移除敌军有益 4 张 + 援护 3 张已入库**（2026-09-19 p7）：看破、索敌、驱逐、火积、援护、移花接木、一夫当关。新增引擎能力：① 输出 `remove_buffs` + `isBeneficialStatus`（属性看 `amount` 正负、增减伤看 `direction` 正负、其余白名单），并按**来源优先级过滤**（用户口径：**被动 > 指挥 > 主动 = 追击**——追击/主动只能清主动/追击来源的有益，指挥/被动增益清不掉）；② `cover.protectId` + 输出 `grant_cover`（援护单体：cover 挂保护者、只代受该友军普攻；「援护友军全体」仍不填 protectId）；③ `strategy_damage.dotFormula`（火积「立即受到燃烧伤害」= 当场结算 + 燃烧（DoT）公式，并以 `dotType:'burning'` 参与 dotTypes 过滤）；④ `damage_reduce.defenseScaled`（一夫当关受防御缩放）。受谋略/受防御缩放段（驱逐 110%、火积 192%、一夫当关 50%）`growthRate` 留空，已登记《成长率待补名单》§三。发动率区间按仓库口径取上界（看破 40% / 援护 45% / 移花接木 40%）。
- **兵力比例 / 闪击 2 张已入库**（2026-09-19 p8）：亡命一搏（B）、闪击（B）。新增能力：`physical_damage.rateBySelfTroopRatio`（按施法者当前兵力比例替换伤害率：低于初始 25% → 160 换 460）。闪击为**纯数据**（`damage_boost caused -99.99` + `attackOnly` + `charges:1`）；「大幅度降低」无数值按用户口径取辕门射戟同款「伤害降至引擎下限 10%」（同种子双跑：buffed = 兵力基础 + 其余 ×10%，±1）。
- **兵力阈值 / 恢复次数 2 张已入库**（2026-09-19 p9）：甚陷不惧（A）、胜敌益强（A）。新增能力：① `PassiveSkill.troopThresholdBuff`（受击实际扣兵后逐档检查 90/70/50/30%，每档去重、跨多档只结算一次）；② `trigger_boost` 新增 `mainSkillOnly`（仅携带者主战法）/`damageSkillsOnly`（输出含物理或策略伤害段）/`expireAfterOwnAct`（行动末清除——甚陷不惧「下次行动时」，用户确认）；③ `General.mainSkillId`（原先只有 mainSkillName，无法按 id 过滤；由 hero-utils 注入）；④ `PassiveSkill.recoverEachRound`（按回合取恢复次数 1/2/3/4，逐次结算、围困拦截）+ `heal.defenseScaled`（受防御缩放）。胜敌益强恢复 120% 受防御未给成长率 → `growthRate: 0`，登记《成长率待补名单》§三。

**确认仍缺（仅列 A/B/S）**：战法距离+1 + 阵营条件（合纵连横） / 恢复次数递增（胜敌益强） / 追击多段（乘胜追击） / 女武将组合（美人计） / 准备跳过（胜兵求战 / 谋定后动） / 兵力阈值发动率（甚陷不惧） / 造成·受到伤害后叠层（以直报怨 / 久战熟谋 / 乘间击隙 / 勠力同心 / 势无虚动） / 试图发动前（众谋不懈） / 主动伤害大幅下降（反计之策） / 每回合概率双效果·几率递增（鸟云山兵） / 目标下次行动前结算（道行险阻） / 造成伤害后再结算（翕处还张） 等。
C/D 级（临危 / 抢攻 / 死士突击 / 觑隙 / 援军之策 / 长驱直入 / 云梯 / 先驱 / 投石轰击 / 毁墙）按用户口径不实现。已解决：**兵力比例/闪击**（p8）；**移除敌军有益**（p7）；**援护**（p7）；反击 / 诱敌深入 / 受击链路（p6）；士气比较与降低（p5）。

## 三、机制补全后实施路径

1. **机制实现**：在 `src/engine/` 补全对应机制（受击 hook → `onAttacked` 事件点；追击多段 → `triggerPursuitSkill` 改造等）。
2. **取出战法**：`SELECT * FROM skills WHERE status='skipped' AND mechanism_key='<键>'`（或本文件按机制分组查）。
3. **实现战法**：按录入规则（`src/data/skills.ts` 定义 + 每战法 3 测试）逐个实现。
4. **更新 DB**：`mechanism_key` 已实现机制的 key → 战法 `status` 改 `implemented`、补 `mechanism_tags`。
5. **同步本文件**：移除已实现机制分组，更新清点。
