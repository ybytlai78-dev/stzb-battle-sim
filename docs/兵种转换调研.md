## 一、结论摘要（先看这 7 条）

1. **每个五星武将恰好两个二级兵种转换方向**，数据形态为 `基础兵种 + 2 个二级兵种代码`；458 条五星条目全部符合（仅占位 NPC「侍卫」无数据）。
2. 两个方向**可以跨兵系**：如 `太史慈（吴弓）→ 弩兵 / 弓骑兵`、`郭嘉（魏骑）→ 死士 / 轻骑兵`（死士属弓兵系）。
3. 二级兵种 = **13 个常规**（步 5 / 弓 3 / 骑 5）+ **5 个武将专属**（解烦兵·孙权 / 白毦兵·陈到 / 西凉铁骑·马超 / 白衣死士·司马懿 / 木牛流马·姜维）。
4. 每个二级兵种 = **1 个专属特性（随兵种、不可更换）+ 2 个通用特性栏**（兵系通用特性，可自选；5 星武将兵种进阶后开第 2 栏）。
5. **通用特性按兵系成池（现版每系 5 个）**，**同兵系所有高级兵种共享同一池**——骑兵系 5 个兵种都能选 出奇 / 疾行 / 难测 / 扰后 / 挫锐。⚠️ 2025-06-25 官方已**移除 6 个特性**（步兵 固阵·近战、骑兵 乱阵·侧击、弓兵 射马·伪装），本轮**不实现已移除特性**。
6. ⚠️ **数值存在多个版本**，本文以 **2025-12-31 官方平衡性调整后的现版**为主，历史版本（2016 初版 / 2018 改版）差异单列在 §五。
7. ⚠️ **「赛季兵种」是另一套系统**（市井铜钱购买 + 指定武将追加效果），**已按口径排除**；但兵种名会重名（白毦兵、西凉铁骑、解烦兵），详见 §四.4。

### 3.3 解码方法（代码 → 中文名，可复现）

官方表 `hero_type_availible` 形如 `"2,22,32,"`：

- **单字代码 = 基础兵种**（1=弓、2=步、3=骑）；

### 4.5 兵系通用特性（可自由学习，每兵种 2 栏）

**体系口径（已核实）**：
- 每个高级兵种 = **1 个专属特性**（随兵种、不可换）+ **2 个通用特性栏**（5 星武将兵种进阶后开第 2 栏）；
- 通用特性是**按兵系（步/弓/骑）成池**的，**同一兵系内所有高级兵种都能学同一批特性**——官方 Q&A 原文「不同的高级兵种可学习同样的通用特性，即**每个高级兵种使用独立的通用特性库**，互相之间不干扰」；
- 同一兵种下不可学 2 个相同特性；学习状态与**兵种**绑定（转走后转回来仍在，官方例：荀彧轻骑学了「疾行」，转重骑后仍保留在轻骑里）；
- 因此：**轻骑、铁骑、重骑、弓骑兵、象兵 都能从骑兵系现版 5 个特性里任选 2 个**（出奇 / 疾行 / 难测 / 扰后 / 挫锐）；弓兵系 3 个兵种共享 5 个；步兵系 5 个兵种共享 5 个。

### 象兵实现要点（#8 展开，实现时注意）

「所有指挥 tag 都对象兵无效」在现有引擎里是**模型级改动**，需要覆盖以下位置：

| 位置 | 现有语义 | 象兵需要 |
|------|----------|----------|
| 一类指挥（`phase:'prep'`） | 准备阶段锁目标、存 `lockedCommands`，目标行动时判定/结算 | 目标为象兵时**整段跳过**（既不挂 `roundRepeat`，也不吃 `delayedOutput` 伤害，也不吃正面 buff） |
| 二类指挥（`phase:'round'`） | 武将行动时判定 | 象兵**不作目标**、也不因在场而受影响 |
| 指挥伤害 | `positional_physical_damage` / 指挥段伤害 | 结算前过滤掉象兵目标（若全队皆象兵则该段空转） |
| 指挥施加的状态 | `inflictStatus`（战必/反计/白衣/其疾如风/金匮要略…） | 对**象兵**目标的施加**直接 return**（不发 `status_conflict`，静默不生效） |
| 指挥恢复（如金匮要略、皇裔流离的 first_aid） | 挂 `first_aid` 状态 | 象兵**不挂** |
| 我方指挥增益（如其疾如风连击、大赏三军增伤） | 全队生效 | **象兵吃不到**（与敌方指挥减益一视同仁） |

> 判定口径建议：以**战法类型 tag**（`Command` / `phase:'prep' | 'round'`）为准，而不是按具体战法 id 白名单；**专属/通用兵种特性不在指挥范畴**，照常生效（如象兵自己的「野性」、通用特性、宝物等）。⚠️ 这条需要实现时确认一次边界：**指挥战法里的「非施加类」效果**（如对施法者自己的属性、对地形的效果）是否也一律不作用于象兵——按用户口径「所有指挥 tag 都无效」应理解为**象兵不受任何指挥战法产生的效果影响**。
