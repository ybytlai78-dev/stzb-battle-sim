# 移动端访问说明（手机横屏）

## 一、手机访问方式

手机与电脑连接**同一个 Wi-Fi / 局域网**，然后在手机浏览器（建议 Chrome / Safari）打开：

```
http://<电脑局域网IP>:5173
```

电脑局域网 IP 查看方式（Windows）：

```
ipconfig        → 无线局域网适配器 WLAN → IPv4 地址（如 192.168.1.23）
```

### 方式 A：开发模式（推荐，改动即时生效）

```bash
npm run web:host     # 等价于 vite --host，监听 0.0.0.0
```

### 方式 B：构建产物（部署 / 分享）

```bash
npm run web:build    # 生成 dist/
npm run preview:host # 本地预览，等价于 vite preview --host，端口 4173
```

也可把 `dist/` 整个目录丢到任意静态服务器（Nginx、GitHub Pages 等）直接访问。

### 常见问题

- **手机打不开**：Windows 防火墙可能拦截了 Node。放行一次即可：
  设置 → 防火墙 → 允许应用通过防火墙 → 勾选 Node.js（专用网络）；
  或临时关闭防火墙测试。
- **端口被占用**：换端口启动 `npx vite --host --port 8080`，URL 同步改。
- **无法确定 IP**：用 `npm run web:host` 启动后，终端第一行会直接打印可访问的局域网地址。

## 二、横屏适配说明

- 页面为**固定单屏**设计（顶栏 / 配将三列 / 底栏），横屏下自动压缩：
  顶栏隐藏副标题、卡槽与武将卡片缩小、底栏参数紧凑、印章入口放大为触控目标。
- **刘海屏安全区**：已适配 `env(safe-area-inset-*)`，内容不会顶进刘海/底部横条。
- **iOS 细节**：输入框字号 ≥16px，聚焦时不会自动放大页面；双击缩放已禁用。
- **竖屏**：降级为整页纵向滚动，不会布局错乱（建议横屏使用以获得最佳体验）。

实现文件：`vite.config.ts`（host 监听）、`index.html`（viewport-fit=cover）、
`web/mobile.css`（全部移动端样式）、`web/main.ts`（引入 mobile.css）。
