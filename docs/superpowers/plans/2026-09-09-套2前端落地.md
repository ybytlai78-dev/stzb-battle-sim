# 套2 三列配将台前端落地 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把已验收的套2高保真（`design-demos/02-workbench.html`）落到生产 `web/`：配将仍是三列工作台，战报统计/详情按原型骨架接真实引擎战报。

**Architecture:** 不改引擎。只换皮肤与战报 DOM。`createStatsView` / `createBattleView` 换布局但继续吃 `BattleReport` 与现有 `computeDetailedStats` / `computeContributionShares` / 事件流。配将交互（拖拽、互斥、加点、部队加成）保持 `teamEditor.ts` 现有 API。

**Tech Stack:** 纯 DOM + CSS（`web/*.ts` / `web/styles.css` / `web/mobile.css`），Vitest + jsdom。视觉对照：`design-demos/02-workbench.html`。

## Global Constraints

- 视觉真理：`design-demos/02-workbench.html`；spec：`docs/superpowers/specs/2026-09-09-战斗模拟器前端ui-design.md` 的「验收后锁定」。
- 不要实现套1 沙盘，不要读它当布局参考。
- 不要改 `src/engine/**`；禁止 `Math.random` 进引擎。
- 伤害实验室布局不重做；仅允许 CSS token 继承。
- 颜色一律 `var(--color-*)`，禁止组件里裸 hex（inline SVG 除外）。
- 品级：S `#d989a0` / A `#4a7ab0` / B `#4e8a62`。
- 统计行序：红大营→中军→前锋，再蓝前锋→中军→大营。
- 统计/详情头像：`avatarSrc`（`_s.jpg`）。简略/配将槽可用 `portraitSrc`。
- 战报页无「战斗模拟器」顶栏；简略/统计/详情在底栏中段。
- JSDoc 中文。
- **不要 git commit**（除非用户本会话明确要求）；跳过所有 Commit 步骤。
- 横屏手机为主，桌面加宽同一骨架；竖屏沿用 `mobile.css` 可滚动降级，不精修。
