范围来源：`dateyuan/通用战法待添加名单.md`（只做 B 级及以上拆解通用）；推进口径 **B**（允许补少量通用机制，按「补一处解锁一批」排期）。

## Objective

为拆解通用战法补引擎缺口并完整入库第一批 7 个 B+ 战法，使「受普攻反击 / 扣兵前规避 / 受击叠层 / 挑衅回血 / 前 N 回合被动」都能按官网满级描述结算。成功标准：7 个战法均可装配、机制事件可测、不做部分实现；受速度成长率留空，只用基值。

本 spec **只覆盖第一阶段**。第二阶段（兵种过滤）、第三阶段（增减伤维度）、第四阶段（士气 / 距离+1 / 特殊目标等）另开 spec。

## 已确认决策

1. 本批只做 B 级及以上拆解通用的 **第一阶段 7 个**：回马、空城、攻其不备、健卒不殆、反击之策、以诱待来、先声夺人。
2. 允许补少量通用机制，不抽事件总线。
3. 攻其不备「攻击」= **全部物理**（普攻 + 攻击战法），不含策略 / DoT。
4. 空城 70% 成功可以免疫 **打出这次判定的那一下**。
5. 受速度成长率留空：`speedScaled: true` 且无 `growthRate` 时用 11.6% 基值。
6. 以诱待来恢复描述未写受谋略：`strategyScaled: false`、`growthRate: 0`。
7. 以诱待来挑衅 `duration: 2`（行动中施加，覆盖来源下次行动）。
8. 反击二次伤害不再触发 `onHurt`（沿用 `resolvingHurtHooks`）。
9. 准备阶段：有 `onHurt` 且 `output` 非空时仍只登记钩子（典韦 / 盲侯不变）。
10. 本阶段不做：垒实迎击、诱敌深入、百战无怯、大幅度三张（反计之策 / 十面埋伏 / 闪击）、受谋略战法。

## 引擎

### `applyDamage` 伤害来源

签名增加可选 `damageSource?: 'basic' | 'skill'`（缺省不传 = `onHurt.damageSource` 视为匹配，避免直构 ctx 的旧单元测试全改）。

| 来源 | `damageType` | `damageSource` |
|------|----------------|----------------|
| 普攻 `dealAttack` | `physical` | `basic` |
| `physical_damage` / 分兵 / `positional_physical_damage` | `physical` | `skill` |
| `strategy_damage` / delayedOutput 策略 / DoT / 诅咒 / 引燃 | `strategy` | `skill` |

### `OnHurtConfig` 增量

现有字段不动。`PassiveSkill.onHurt` / `CommandSkill.onHurt` 类型改为 `OnHurtConfig | OnHurtConfig[]`（单条写法兼容）。新增：

- `damageSource?: 'basic' | 'any'`：缺省 `any`。`basic` = 只吃 `damageSource:'basic'` 的普攻。
- `timing?: 'before_damage' | 'after_damage'`：缺省 `after_damage`（现有盲侯 / 典韦 / 于禁 / 贾充）。
- `startRound?: number` / `endRound?: number`：钩子生效回合窗口（空城 `endRound: 2`）。
- `victim` 增加 `'locked'`：仅当受伤者是该施法者该类指挥在 `lockedCommands` 里的目标（攻其不备）。
- `thisHitReduce?: number`：`before_damage` 判定成功后，本段伤害乘 `(1 − rate)`（健卒 0.5）。
- `onlyIfSourceTauntsVictim?: true`：仅当 `source` 带 `taunt` 且 `targetId` 为受伤者（以诱待来回血）。

`maxStacks` 对 `applyTo:'victim'` 同样生效（攻其不备 5 层）：已达上限则不再施加。

### 扣兵前顺序

`applyDamage` 在实际扣兵前：

1. 跑 `timing:'before_damage'` 的钩子。`before_damage` 与 `after_damage` 共用 `resolvingHurtHooks`：反击等二次 `applyDamage` 两条都不跑，避免空城 / 健卒在反击段上再套一层。
2. 若钩子 `grant_evasion`，当场 `consumeEvasion`；成功则发 `evasion_blocked`、**本段不扣兵**、不跑 after 钩子。
3. 累加本段 `thisHitReduce`（多次独立成功则各自乘算，或只取本次钩子自己的一次；健卒只有一条，实现按一次即可）。
4. 扣兵（含伤兵死亡拆分）。
5. 现有引燃 / 急救 / `timing:'after_damage'` 的 `triggerOnHurt`。

空城未判定成功：本段照扣。已有规避在调用方 `consumeEvasion` 已挡掉的，根本不会进 `applyDamage`（空城只处理「进 applyDamage 时还没有规避」的当次）。

### `counter` 状态

```ts
| { type: 'counter'; duration: number; rate: number }
```

携带者被 **普攻** 实际扣兵后，对来源打 `rate%` 物理（`rate` 与 `physical_damage` 同口径，100 = 100%；`calcDamage` 普攻公式、吃增减伤与兵种克制）。不消耗状态。二次伤害走 `resolvingHurtHooks`，不再反击。杀伤统计归属携带者。

`roundStartRepeat` 在回合开始、任何人行动前挂上的 `counter`（`duration:1`，`appliedRound=当前回合`）覆盖**本回合全过程**（含携带者行动之后、敌方后手普攻）；该单位下一回合行动开始时按既有规则递减移除。新一轮 `roundStartRepeat` 会在递减之前先挂上新的一层。

### `damage_boost.speedScaled`

与 `defenseScaled` 并列：`scaledValue(|rate|×100, growthRate, effectiveStat(caster, 'speed'))`，八舍九入后还原符号。`growthRate === undefined` 时不缩放、用基值。

### 被动窗口

`PassiveSkill` 增加可选 `startRound?: number` / `endRound?: number`。`actUnit` 里 `timing:'round_start'` 的被动：当前回合不在窗口内则跳过整次结算（先声夺人 `endRound: 3`）。`battle_start` 型不受此字段影响。

### `roundStartRepeat` 窗口 + 指挥 `chance`

```ts
roundStartRepeat?: {
  output: SkillOutput[];
  startRound?: number;
  endRound?: number;
};
```

`tickRoundStartStatuses` 里超出窗口则跳过。`executeSkillOutputs` 的输出级 `chance` 从「仅 `skill.type==='passive'`」放开到指挥（反击之策 75% 走士气修正并发 `skill_trigger`）。

### 准备阶段登记

现有逻辑保留：`onHurt` 战法准备阶段只登记、不立刻 `executeSkillOutputs`（`output` 留给受击）。`roundRepeat` / `initialOutput` / `delayedOutput` 不受影响。反击之策无 `onHurt`，靠 `roundStartRepeat`，准备阶段只锁目标。

## 战法

id 用拼音，挂 `SKILL_REGISTRY`。成长率未知不写 `growthRate`。

### 回马 `huima`（B 被动）

- `timing:'battle_start'`（只登记钩子）
- `range: 1`，`targetMode:'self'`

- 必中、不限距离。tags `['damage']`

### 空城 `kongcheng`（B 指挥 · 一类 prep）

- `range: 1`，`targetMode:'self'`，`targetSide` 缺省

- 判定成功后当场消耗该层规避，免疫当次。第 3 回合起钩子不跑。tags `['evasion']`

### 攻其不备 `gongqi_bubei`（S 指挥 · 一类 prep）

- `range: 5`，`targetMode:'group'`，`groupCount: 2`，`targetSide:'enemy'`
- 准备阶段锁 2 目标，不立刻结算 output

- 无 `growthRate` → 每层 11.6%。同战法累加，满 5 层停。tags `['damage_boost']`

### 健卒不殆 `jianzu_budai`（A 被动）

### 反击之策 `fanji_zhice`（B 指挥 · 一类 prep）
