## 已确认决策

1. 本批做满 **9 个**：方圆、疏数、衡轭、锋矢、鱼鳞、鹤翼、白刃、全军突击、飒沓如星。
2. 受谋略 / 受防御 / 受速度 **一律满级基值**，不写 `growthRate`。
3. 阵容条件按 **开场上阵单位的兵种集合**（含之后阵亡者仍计入）；集合 ⊆ 允许的两种即生效。3 弓算「仅由弓+骑组成」。混入第三兵种则整法不挂。
4. 3 人队里「我军群体 3」= 我军全体。效果「全体 X 兵」= 在战法选中的友军里再滤 `troopTypes`（不另开全队扫描）。飒沓如星是群体 **2**，只滤这 2 人里的骑兵。
5. 方圆「主动、追击」含追击；锋矢原文只有「主动战法」，**不含追击**。
6. 「普通攻击伤害」含普攻与由其触发的分兵（`damageSource:'basic'`）。主动 / 追击 / 指挥打出的攻击不吃。
7. 白刃「进行策略攻击的伤害降低」= 造成侧、仅策略（`direction:'caused'`, `damageType:'strategy'`），敌我全体。
8. 全军突击「接下来 2 次攻击」= 现有 `charges:2`（普攻或战法输出各消耗 1 次）。飒沓「下 2 次普通攻击进入分兵」= `split.charges:2`，只在普攻时消耗。
9. 不抽新 `FormationSkill` 类型，不在 `action.ts` 为单战法写死分支。

## 引擎

### 方案（采用 A）

在现有一类指挥 / `inflict_status` / `damage_boost` 上加可选字段。不新开阵法类型，不按战法名特判。

未采用：独立 `FormationSkill`（过重）；9 个 `if (skill.id===…)`（破坏数据驱动）。

### 1. 阵容条件 `teamTroopFilter`

`CommandSkill`（及需要时的 `ActiveSkill`）增加：

```ts
/** 开场上阵单位的 troopType 集合必须 ⊆ 此列表，否则本战法整次不生效（疏数弓+骑） */
teamTroopFilter?: TroopType[];
```

检查时机：准备阶段（指挥）或发动时（主动），读该侧 **部署名单**（`ctx.myTeam` / `enemyTeam` 的 `general.troopType`，不论 `alive`）。通过才 `executeSkillOutputs` / 登记 `roundStartRepeat`。失败不发 `skill_cast`。

战斗中不再复查。

### 2. 目标兵种 `troopTypes`

`SkillOutput` 的 `inflict_status` / `remove_debuffs` / `physical_damage` / `grant_damage_boost` 增加：

```ts
troopTypes?: TroopType[];
```

结算时从当前目标池滤 `target.general.troopType`。缺省不过滤。

### 3. 增减伤维度

`CreateStatus` / `Status` 的 `damage_boost` 与 `damage_reduce` 增加可选：

```ts
damageSource?: 'basic' | 'skill'; // 缺省 any（普攻+战法都吃）
skillTypes?: SkillType[];         // 仅 skill 时再限制；缺省不限制
damageType?: 'physical' | 'strategy'; // 缺省 any
```

`damageBoosts` / `sumRates` / `collectDamageModifiers` 必须带上 **本次伤害上下文**（来自 `applyDamage` 的 `damageSource` + `damageType` + 可选 `skillType`）：

| 路径 | damageSource | skillType | damageType |
|------|--------------|-----------|------------|
| `dealAttack` / 分兵 | `basic` | 无 | `physical` |
| 主动 `physical_damage` | `skill` | `active` | `physical` |
| 追击攻击 | `skill` | `pursuit` | `physical` |
| 指挥攻击（含代打、positional） | `skill` | `command` | `physical` |
| 策略伤害 / DoT | `skill` | 该战法类型 | `strategy` |

条目不匹配则 **不计入** 本次 `buffMult`（视同不存在，不是乘 0）。旧状态三项皆缺省 → 行为与现在完全相同。

`charges` 消耗规则不变（一次普攻或一次战法输出扣 1）；全军突击的 +28% 用 `charges:2`，不设 `damageSource`（「攻击」= 现有 charges 口径）。

### 4. 分兵 `charges`

```ts
| { type: 'split'; duration: number; rate: number; charges?: number }
```

有 `charges` 时不按回合摘（`duration` 仍可写 999）。每次 **普攻触发分兵** 后 `charges -= 1`，到 0 移除。无 `charges` 的鹤翼分兵仍走 `duration:1`。

### 5. `roundStartRepeat.oddRounds`

```ts
roundStartRepeat?: {
  output: SkillOutput[];
  startRound?: number;
  endRound?: number;
  /** 仅第 1/3/5/7 回合（鹤翼） */
  oddRounds?: boolean;
};
```

`oddRounds` 与窗口同时生效：当前回合为奇数才跑。

### 6. 代打攻击 `attacker:'recipient'`

`physical_damage` 增加 `attacker?: 'lowest_strategy_ally' | 'recipient'`。

`'recipient'`：对 **每个通过兵种过滤的目标**，以该单位为攻击者、按其攻击/兵力/造成侧增减伤，对距离 `range`（输出级，缺省战法 range）内敌军 `targetMode:'single'`（均匀随机）打一段攻击。杀伤 `creditToId` 归 **该骑兵**（疏数是骑兵在打，不是施法者）。`chance` 仍走士气，逐人判定。

二次伤害不触发该骑兵的 `onHurt` 反击链之外的事：这是普通 `applyDamage(..., 'physical', 'skill')`。不设 `resolvingHurtHooks` 特例（疏数不是反击）。

### 7. 准备阶段登记

有 `roundStartRepeat` 的一类指挥：准备阶段仍锁目标、可跑 `output` / `initialOutput`；阵容条件失败则两者都不登记。

`output: []` 仅靠 `roundStartRepeat` 的（疏数的每回合攻击）允许，同反击之策。

### 8. 白刃两段

- `output`：敌我全体策略造成 −35%（`duration:3`，对齐大赏三军「前 3 回合」）+ 我军骑/步防御 +45 `duration:3`。
- `roundStartRepeat: { startRound:4, endRound:4, output: 我军骑/步攻击 +45 duration:3 }`。

敌我全体：一段 `inflict_status` `targetSide` 覆盖做不到两侧时，拆成两条 output（`targetSide:'ally', targetMode:'all'` 与 `targetSide:'enemy', targetMode:'all'`），不受战法「我军群体 3」限制。防御/攻击两条仍走锁定友军 + `troopTypes:['cavalry','infantry']`。
