# Spec: 五星主战法第一刀（沙摩柯 / 张飞 / 褒姒 / 夏侯渊 / 祝融 / 郭皇后）

日期：2026-09-16  
状态：已确认（2026-09-16）。实现计划：`docs/superpowers/plans/2026-09-16-五星主战法第一刀.md`。

## Objective

给 115 五星池中主战法仍空槽、且不属七将调研的武将补全机制。本批只录入 6 人，按战法描述做全、不部分实现。受谋略 / 受速度的成长率留空（结算用基值），不编造。

成功标准：六人 `mainSkillId` 非空；描述前半的效果都能在引擎里打出对应事件 / 状态；成长留空的测基值。

## Tech Stack

- 引擎：TypeScript（`src/engine`），确定性，随机只走 `rng.ts`
- 战法数据：`src/data/skills.ts` + `scripts/build_heroes_seed.mjs` 的 `SKILL_ID_BY_NAME`
- 测试：Vitest；新文件 `tests/main_skills_b20.test.ts`（仓库已有 b19）
- Web 下架：`src/data/listing.ts` 的 `OFFLINE_MAIN_SKILLS`（成长未确认的主战法）

## 已确认决策

1. 范围 = 这 6 人。七将（曹纯 / 羊祜 / 马岱 / 马谡 / 汉荀彧）与通用战法本批不做。SP 赵云 / SP 姜维跳过。
2. 官网两段拼接 **只用前半**（与 `heroes.json` 已清洗文案一致）：张飞群体 450%；夏侯渊只有首次攻击 +70%；沙摩柯只有混乱，不加承伤。
3. 虎步关右按 **B**：每次成功发动后给「下一次攻击伤害」+70%；120% 几乎每回合都会挂。只吃物理（普攻 + 物理战法），不吃策略。已有未消耗的 charges 层则不刷新（同扬威）。
4. 火兽冲锋：同一 50% 成功才打 160% + 挂下一次普攻额外 +160%；与常驻普攻 +80% **加算**。
5. 文德椒房：每次「本回合首次主动成功」后 **重选** 距离内 2 友军。当次 2 人各 +1 层，每人最多 3 层；没选中的人层数保留到战斗结束。
6. 成长率不写字段 = 不跑 `scaledValue`，用基值。受谋略 / 受速度的主战法进 `OFFLINE_MAIN_SKILLS`。
7. 实现走战法数据驱动，不抽事件总线，不给单个武将写死。
8. 落首箭：第一段随机单体 300%；第二段 **必打大营** 180% + 混乱。第一段打的就是大营时，大营吃两刀再上混乱。
9. 烽火覆周：只打策略火攻，不挂燃烧。连锁 60%→40%→20%，每次独立选目标，判定走士气。发动率 50%–100% 每次均匀随机。
10. 长坂之吼 2 回合准备：准备期间仍可普攻、不再判定其他主动。进入准备的那一回合不算「主动发动成功」（文德椒房）；准备完成释放的那一回合算。
11. 混乱 `duration: [1, 2]` 与方阵突击同一套数字语义（持续 1 回合 = `duration: 1`），不做 +1 换算。50/50 取 1 或 2。
12. 不要 git commit，除非本会话明确要求。

## 引擎

### 2 回合准备

`PreparedActiveSkill` 增加 `prepareTurns?: number`，缺省 `1`（现有 1 回合准备战法零改动）。

`UnitState` 增加 `prepareLeft: number | null`（缺省 `null`）。`combat.ts` / 战报 dummy 同步。

发动成功且 `prepare === true`：

- `isPreparing = true`
- `preparingSkillId = skill.id`
- `prepareLeft = skill.prepareTurns ?? 1`
- 发 `prepare_start`，本回合不再判定其他主动（现有 `break`）
- 本回合仍普攻

下次行动走到准备分支时：

- `prepareLeft > 1`：`prepareLeft -= 1`，不释放、不判定其他主动，仍普攻
- `prepareLeft === 1`：发 `prepare_end`，释放，清空 `isPreparing` / `preparingSkillId` / `prepareLeft`

1 回合准备：进入时 `prepareLeft = 1`，下一行动直接释放，行为与现在一致。

### 发动率区间

`BaseSkill.triggerRate` 改为 `number | [number, number]`。区间每次判定用 `rng.intInclusive(minPct, maxPct) / 100` 作为 `base`，再走 `moraleTriggerRate`。烽火覆周 `[0.5, 1]`。

### 无视兵种相克

`physical_damage` 与 `positional_physical_damage` 增加 `ignoresTroopCounter?: boolean`。为 true 时该次 `calcDamage` 不加算克制 −30%（`troopCounterReduce` 视为 0），事件不带 `counterFactor: 0.7`。

### 连锁伤害

`strategy_damage` / `physical_damage` 增加：

```
chain?: { chance: number; decay: number }
```

本段打出后：当前概率 `p = chance`；当 `p > 0` 时按施法者士气做 `moraleTriggerRate(p)`，成功则在战法距离内独立 `random_single` 再打同一段（不含再挂 chain 的递归字段，由循环驱动），然后 `p -= decay`；失败或 `p <= 0` 停止。发 `skill_trigger`（含 rate / baseRate / morale）。烽火覆周：`chance: 0.6, decay: 0.2`。

### `chance_group`

`SkillOutput` 新增：

```
{ kind: 'chance_group'; chance: number; outputs: SkillOutput[] }
```

一次 `moraleTriggerRate`，成功才执行内层全部 output。失败发 `skill_trigger` success:false，内层不跑。火兽冲锋用这个包「160% 刀 + 下一次普攻 +160%」。

### 指挥 `after_first_active`

`CommandSkill.roundTrigger` 增加 `'after_first_active'`。

`UnitState` 增加 `firstActiveSucceededThisRound?: boolean`，回合开始清 false。

`triggerActiveSkill` 发动率成功之后：

- 若本段因准备而 `prepare_start` 返回：**不**置位、**不**触发钩子
- 若实际 `executeSkillWithTargets`（含准备完成释放）：若该单位本回合尚未置位，则置位并触发其 `roundTrigger === 'after_first_active'` 的指挥（施法者未阵亡）。目标每次按战法距离 / `groupCount` **重选**

混乱 / 犹豫导致没走到发动成功：不触发。

### 混乱 duration 区间

`CreateStatus` 的 `confusion.duration`（及其他需要的控制类，本批只用混乱）允许 `number | [number, number]`。施加时 `[a, b]` → `rng.intInclusive(a, b)`。

`inflict_status` 增加 `positions?: Position[]`：有值时忽略战法整体目标，改为选这些站位上仍存活的敌军（落首箭混乱打大营）。缺员则跳过。

### damage_boost：charges 与常驻共存

`sameDamageBoostFilter` 增加：已有实例是否带 `charges` 必须与新施加一致。火兽冲锋常驻普攻 +80%（无 charges）与下一次普攻 +160%（`charges: 1`）是两条，buffMult 加算。

同战法同过滤维的 `damage_boost` 叠层：`stacks` 达到 `maxStacks`（CreateStatus 新增可选 `maxStacks`）后不再加 rate。文德椒房 `maxStacks: 3`。

`growthRate === undefined` 且 `strategyScaled` / `speedScaled` / `defenseScaled` 为 true：不跑 `scaledValue`，用 `rate` 基值。不要写 `growthRate: 0` 冒充「已确认零成长」。

## 测试口径（`tests/main_skills_b20.test.ts`）

木桩沿用 `main_skills_b19` / `universal_b_plus_p1` 的 `dummy` / `level40` / `withSkills`。强制发动用既有改 `triggerRate` / `chance` 的手段。成长留空的断言基值。

**落首箭：** ① h524 准备主动槽含 id。② 强制释放：至少一段 300% 打非大营（或任意单体）+ 一段打大营 180% + 大营有混乱。③ 第一目标钉大营时大营至少两段物理伤害。

**长坂之吼：** ① 装配 `prepareTurns: 2`、`groupCount: [2,3]`、rate 450。② 发动成功当回合 `prepare_start`、下一行动仍准备、再下一行动 `prepare_end` + damage。③ 被克制组合（如步打骑）有 `ignoresTroopCounter` 的伤害事件不带 `counterFactor: 0.7`。

**烽火覆周：** ① 装配 `triggerRate` 为区间、chain 0.6/0.2。② 强制连锁判定成功：多于 1 段 `strategy_damage`，目标可不同。③ 谋略 80 与更高谋略伤害率同为 95% 基值（不缩放）。

**虎步关右：** ① h435 主动槽含 id、triggerRate 1.2。② 发动后自身有 charges:1、rate 0.7、damageType physical；打出一次物理后 charges 消失。③ 策略伤害不消耗、也不吃这 70%。

**火兽冲锋：** ① h494 被动槽含 id；开战有 basic caused +0.8。② 强制 chance_group 成功：一段 160% 物理 + 自身 charges basic +1.6；普攻同时吃 0.8 与 1.6。③ chance_group 失败：无 160% 刀、无 charges 层；常驻 0.8 仍在。

**文德椒房：** ① h655 指挥槽含 id、`after_first_active`。② 郭皇后带一个必中主动，首次成功后距离内 2 友军有 strategy caused +0.1。③ 第二回合再成功：可重选；同一人不超过 3 层；进入准备的回合不叠层，释放回合叠。
