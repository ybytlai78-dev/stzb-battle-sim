## 已确认决策

1. 本批做满 **4 个**：万箭齐发、文伐、不攻、恃强淬锋。缺的机制一并补。
2. 文伐 228% 用调研 **2.1%/点**；万箭 −50%、不攻 83%、恃强 −30%/+3.4% **满级基值、不编造成长率**。
3. 万箭齐发以 extra 200714 为准：无准备、发动率 35%、物理 150%、敌军**群体 2**、策略造成 −50% 受攻击。classified「准备全体 180% + 大幅度」作废。
4. 万箭「持续 1 回合」= 行动中施加 **duration 2**（与辕门射戟同口径）。
5. 文伐 +20%：228% **打完再挂**；taken、仅策略、charges 1、不按回合掉；**受击方**吃到匹配的策略伤时消耗；当次 228% 不吃。
6. 不攻「无法普通攻击」= 给自己挂整场 **怯战**（复用现有状态，不新开禁普攻）。
7. 不攻每回合 83% = 一类指挥 **`roundStartRepeat`**（`tickRoundStartStatuses`：回合开始后、单位行动前），距离 5 敌军单体。
8. 恃强减伤 1/5 = 挂上时满额分 **5 份**，每次受到策略伤害 −1 份，5 次后移除（30→24→18→12→6→0）。
9. 恃强 +3.4%：回合开始 +1 层，且每次造成物理伤害（普攻 / 战法物理 / 分兵 / 反击）+1 层；两路都能叠；封顶 12；caused、仅物理。
10. 方案 A：只加可选字段，不按 `skill.id` 特判。

## 引擎

### 1. `attackScaled`

`CreateStatus` / `Status` 的 `damage_boost`（及对称的 `damage_reduce`）加：

```ts
attackScaled?: boolean;
```

结算对齐 `defenseScaled` / `speedScaled`：`attackScaled && growthRate !== undefined` 才 `scaledValue(rate, growthRate, 生效攻击)`；**无 `growthRate` 用原 rate**（万箭 −0.5、恃强 −0.3 / 0.034）。

百分比增减伤的 `rate` 仍是小数（0.5 = 50%）。

### 2. taken `charges` 在受击消耗

现有 `consumeAttackCharges` 只在**攻击者打出**时扣（青丘媚祸「下一次攻击」）。

文伐是目标 **下一次受到策略攻击**：

- 状态：`damage_boost` `direction:'taken'` `damageType:'strategy'` `rate:0.2` `charges:1`（无 `growthRate`）
- `applyDamage` 在策略伤 **实际扣兵前**（已过规避、进入结算）：若该 taken 状态 `statusMatchesHit`，则本次 `damageBoosts` **仍然计入**，结算后再 `charges -= 1`，到 0 移除
- 物理受击不匹配，不消耗
- 造成侧 `charges`（全军突击 / 青丘）路径不变

顺序：先算包含该层的伤害 → 再扣 taken charges（当次吃得到，下一次没有）。

### 3. `decayFifths`

对齐谋议宏图 `decayEighths`，但触发点是 **受到匹配的策略伤害**，不是回合开始。

`CreateStatus`：`decayFifths?: number`（恃强 = 5）。`Status` 存 `fifths` + `baseRate`。  
每次目标受到 `statusMatchesHit` 的策略伤且实际扣兵 > 0：`fifths -= 1`，`rate = baseRate * fifths / 5`（符号与 baseRate 同）；`fifths <= 0` 移除。

恃强减伤用 `damage_boost` taken 负值 + `damageType:'strategy'` + `attackScaled` + `decayFifths:5`（与鱼鳞「受到策略降低」同方向模型，外加衰减）。

### 4. 被动造成物理叠层

`PassiveSkill` 已有 `roundStartRepeat`，但现口径是 **该武将行动阶段、主动/普攻前**（火兽冲锋），**不是**「每回合开始」。恃强「每回合开始时」不要走这条。

新增可选（仅自身）：

```ts
/**
 * 自身造成物理伤害叠层（恃强淬锋 +3.4%/层）。
 * onRoundStart：tickRoundStartStatuses 给持有者 +1 层。
 * onDealPhysical：持有者造成普攻/战法物理/分兵/反击且实际扣兵后 +1 层。
 */
selfPhysBoost?: {
  perStack: number;
  maxStacks: number;
  duration: number;
  attackScaled?: boolean;
  onRoundStart?: boolean;
  onDealPhysical?: boolean;
};
```

层数走现有 `damage_boost` `stacks` + `sameSource` 累加，到 `maxStacks` 停止。`rate = perStack * stacks`（或每层独立同战法累加 rate，封顶 maxStacks）。caused、`damageType:'physical'`。

本批 **不** 用该钩子登录百战无怯。

### 5. 追击发动率区间

文伐 extra `20%-40%`。`BaseSkill.triggerRate` 现为 `number`。本批扩为 `number | [number, number]`：判定时 `rng` 在闭区间均匀取（与 groupCount `[2,3]` 同随机源）。缺省标量行为不变。

### 6. 不攻复用怯战

一类 `phase:'prep'` `targetMode:'self'`：

- `inflict_status` 怯战 duration 999
- `inflict_status` 策略造成 +25%（`damageType:'strategy'` `direction:'caused'`，无 attackScaled）
- `roundStartRepeat.output`：`strategy_damage` rate 83 `strategyScaled:true` 无 `growthRate`，`targetMode:'single'`，距离用 **5**（战法 range 是 1，输出须 `ignoreRange` 或输出级 `range:5`——实现时给 `strategy_damage` 可选 `range`，缺省 `skill.range`）

怯战冲突规则不改。不攻打在自己身上，与敌军战必不冲突。
