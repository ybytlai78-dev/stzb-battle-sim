## 一、结论（按 m00265 口径更正）

用户的机制判断成立：**DoT 的伤害与增减伤在施加那一刻就算好了**（`computeDotTickDamage`，`action.ts:2433-2477`），
所以只要「施加时施法者身上已有卫瓘的谋略层」，月英与灵帝的 DoT 就会吃到 —— 这与吕蒙的预存伤害是同一类时序。
上一版把它写成「结构上不通」是错的，更正如下：

| 武将 | 结算点 | 当前是否叠层 | 修好后能否吃谋略层 |
|---|---|---|---|
| 吕蒙 白衣渡江 | prep 预存伤害（R3 打出） | **已叠**（3 层谋略） | 已通 |
| 灵帝 帝临回光 | prep 预存（无伤害段，空）+ R3 施加恐慌 | prep **叠错轴**（攻击 3 层）；R3 施加**不叠** | **能**，两处都要改 |
| 黄月英 匠心不竭 | R1/R3/R5 施加恐慌 / 燃烧 / 妖术 | **完全不叠** | **能**，需接施加前叠层；神兵/大赏另需 prep 有结算点 |

## 二、三层结算点：谁叠、谁没叠（`triggerStackBuff` 调用点）

| 结算点 | 代码 | 是否先叠层 |
|---|---|---|
| prep 预存伤害（`delayedOutput` 有伤害段） | `action.ts:1067-1080` | **是**，两个循环分离：先全员叠、后逐目标算 ⇒ 吃满 3 层 |
| prep 施加状态（`delayedOutput` 无伤害段，灵帝） | 同上循环，类型由 `delayedType` 推导 | 叠了，但**判成 physical** |
| 回合施加状态（`delayedOutputs` 复数，月英 R1/R3/R5） | `action.ts:1439-1450` → `executeSkillOutputs` | **否**，全程无 `triggerStackBuff` |
| DoT 跳伤 | `action.ts:2551` | 是（`'strategy'`），但发生在**冻结之后** |

`delayedType` 推导只有一行（`action.ts:1067-1069`）：

```ts
const delayedType = skill.delayedOutput.output.some((o) => o.kind === 'strategy_damage')
  ? 'strategy' : 'physical';
```

帝临回光的 output 全是 `inflict_status`（siege / range_buff / split / **panic**）→ 不含 `strategy_damage` → 缺省 `physical`。
**恐慌明明是谋略 DoT，却把整条战法判成物理** —— 这就是灵帝拿到 3 层攻击（+99）、谋略零增益的原因。

## 三、层寿命：prep 叠的层只活到第 1 回合末（决定性约束）

`addStackLayer`（`action.ts:2384-2424`）造的层是 `{ remaining: 1, appliedRound: ctx.currentRound }`，prep 阶段即 `appliedRound = 0`。

- `markStatusesOnActStart`（`action.ts:2937`）：`if (s.appliedRound === 0) continue;` —— 行动开始**不**递减；
- `tickStatuses`（`action.ts:5277`、`5291-5299`）：`appliedRound === 0` → `remaining -= 1` → ≤0 **移除并 push `status_expired`**。

⇒ **prep 层的实际寿命 = 准备阶段 + 第 1 回合末**。这条决定了两件事：

1. **能吃到 prep 层的，只有「同一 prep 阶段内结算」的东西**：吕蒙的预存伤害、神兵天降、大赏三军（都是 prep 一次性落地）。
2. **R3 / R5 才发生的事，永远吃不到 prep 层** —— 它们只能吃「当回合新叠的层」（DoT 跳伤每回合叠 2~3 层，实测见 §五）。

所以「让神兵/大赏吃到」这个具体诉求，本质是**要求 prep 阶段存在一个叠层触发点**，与 DoT 什么时候打出去无关。

## 八、修法：三处，逐处影响（✅ 已按 a / b / b′ / c 全部落地，见 §〇）

| 位置 | 现状 | 修法 | 影响 |
|---|---|---|---|
| **a** `action.ts:1067-1069` | `delayedType` 只看 `strategy_damage` | 把谋略类 DoT 的 `inflict_status`（panic / burning / sorcery / curse）也判为 `strategy` | 灵帝 prep 由「攻击 ×3」变「谋略 ×3」；神兵/大赏 39%→54%。**副作用：分兵失去攻击层** |

| **b** `action.ts:1439-1450` | `delayedOutputs` 施加前不叠层 | 在 `executeSkillOutputs` **之前**对本次目标逐目标 `triggerStackBuff(ctx, caster, t, 'strategy')` | 月英每次施加 DoT 前先把层叠好 ⇒ 同一次挂载的跳伤即吃到（337 / 381 / 406）；也让灵帝 R3 恐慌吃到 |
