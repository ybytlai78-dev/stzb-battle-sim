# 引擎使用指南（教程原图）

这里放的是 App 内「教程」弹窗的**原始截图**，文件名序号 = 教程步骤顺序：

| 文件 | 教程步骤 |
|---|---|
| `1.jpg` | ① 配将：筛选 · 拖拽 · 拼音搜索 |
| `2.jpg` | ② 点武将 → 详情：配战法 · 配属性 |
| `3.jpg` | ③ 战法背包 |
| `4.jpg` | ④ 伤害测试实验室（配队伍 + 打桩） |
| `5.jpg` | ⑤ 打桩结果：伤害占比饼图 |
| `6.jpg` | ⑥ 统计 · 战法统计（次数 ｜ 杀伤） |
| `61.jpg` | ⑥ 统计 · 武将统计（伤害 / 恢复 / 控制占比）—— 第 6 步的第二张 |
| `7.jpg` | ⑦ 详细战报：逐回合明细 |

- 规格：2640 × 1216 JPEG（模拟器 2× 截图）。
- **App 不直接用这里的原图**：运行时读的是压缩版 `public/tutorial/step*.jpg`
  （1400px 宽、q3，8 张共 ~820KB）。改教程图要两边一起换，否则 `web/smoke.test.ts`
  的「教程截图资源齐备」用例会挂。
- 步骤文案在 `web/tutorial.ts` 的 `TUTORIAL_STEPS`（与上表一一对应，顺序不可乱）。
