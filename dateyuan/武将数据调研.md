## 二、四维属性机制

### 2.1 属性作用

| 属性 | 作用 |
|------|------|
| **攻击** | 提高物理伤害；影响部分受攻击属性加成的战法 |
| **防御** | 降低受到的物理伤害；影响部分防御类战法 |
| **谋略** | 提高策略伤害与恢复量；≥52 时降低受到的策略伤害 |
| **速度** | 决定战斗出手顺序（同无先手时比速度）；影响大地图行军速度 |

### 2.2 成长与升级公式

```
某属性(等级L) = 初始值 + (L - 1) × 成长值 + 自由分配点数
```

- 男性武将：每 10 级获得 **10** 点自由属性（40 级共 40 点）
- 女性武将：每 10 级获得 **15** 点自由属性（40 级共 60 点）
- **COST（统率）** 越高，四维成长通常越高，也是配队 COST 上限的约束
- 游戏内查看：武将详情面板中，成长值显示在对应属性**括号内**

**40 级白板全加点估算（社区常用）：**

```
全X加点40级面板 ≈ 成长值 × 39 + 初始X + 40(男)/60(女)
```

来源：[7723 五星武将40级属性排行榜](https://www.7723.cn/strategy/2366.html)（网易大神@军师团季布）

### 2.3 攻击距离说明

三人阵型位置距离（我方→敌方）：

| 位置关系 | 距离 |
|----------|------|
| 前锋 ↔ 前锋 | 1 |
| 中军 ↔ 前锋 | 2 |
| 大营 ↔ 前锋 | 3 |
| 大营 ↔ 中军 | 4 |
| 大营 ↔ 大营 | 5 |

- **攻击距离**：武将普攻/反击可触及的最远格子，不足则无法普攻
- **战法有效距离**：与攻击距离独立，配置战法时需单独考虑
- 援护/挑衅时普攻不受距离限制

## 六、对本项目的建议

1. **初始值 + 主战法 + 攻击距离**：可直接使用 `docs/_scraped_heroes.json`（官网抓取）入库。
2. **成长值**：需二次采集（游戏内截图 OCR、玩家工具导出、或按版本手动维护 patch）。
3. **战法距离**：主战法描述中的「敌军全体/群体/单体」需结合战法类型单独建模，不能等同攻击距离。
4. **版本同步**：官网注明「以最终游戏内设定为准」，重大平衡后应重新抓取并更新 `patch_version`。
