## 一、战法类型说明

| 类型 | 发动时机 | 说明 |
|------|----------|------|
| **指挥** | 准备回合 | 战斗开始前发动，多数全程或前 N 回合生效 |
| **主动** | 正式回合、普攻前 | 按发动率独立判定，可被犹豫/混乱阻止 |
| **被动** | 战斗开始前 | 全程生效，通常不可被缴械/犹豫禁用 |
| **追击** | 普攻命中后 | 依赖普攻触发，可多次判定 |

释放优先级：**被动 → 指挥 → 主动 → 追击**。

## 二、品质级别

战法品质分为 **S / A / B / C / D**，反映强度、功能性与易用性；**并非品质越高越适合所有队伍**。
