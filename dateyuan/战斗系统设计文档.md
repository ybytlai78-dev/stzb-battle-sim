## 二、战斗流程（初版）

### 2.1 宏观流程

```
[准备阶段]
   ├─ 计算双方三将出场速度 → 排序表
   ├─ 发动被动战法（最小集初版无被动，管线预留）
   ├─ 发动指挥战法（初版无指挥，管线预留）
   └─ 标记战斗开始

[回合 1..8]
   ├─ 回合开始事件（阶段计时、持续效果刷新）
   ├─ 按速度从高到低逐个武将行动（行动阶段，见 2.2）
   ├─ 回合结束事件（DOT/持续效果结算）
   └─ 若任一武将兵力归零 → 立即结束战斗

[战斗结束]
   ├─ 判定胜负（我方全灭 → 败；木桩全灭 → 胜；8 回合到 → 平）
   └─ 输出结构化战报 + CLI 文本
```

### 2.2 单武将行动阶段（标准率土流程）

```
行动顺序：按速度降序；同速 → 速度高者先；仍同 → 站位先手（前锋 > 中军 > 大营）

单个武将行动：
  1. 主动战法判定阶段（普攻前）
     - 按战法槽位顺序逐个判定发动率
     - 发动成功 → 释放（纯伤害型=对目标造成伤害）
     - 未发动 → 记录「未发动」
  2. 普通攻击阶段（若可普攻）
     - 按攻击距离寻敌（见 2.3）
     - 命中 → 计算兵刃伤害（三部分相加模型）
  3. 追击战法判定阶段（普攻命中后）
     - 初版最小集无追击，管线预留

注：初版只实现「主动战法判定 + 普攻」，被动/指挥/追击留管线。
```

### 2.3 攻击距离寻敌

**双方站位距离表（我方 ↔ 敌方）：**

| 我方 \ 敌方 | 敌方前锋 | 敌方中军 | 敌方大营 |
|------------|---------|---------|---------|
| 我方前锋 | 1 | 2 | 3 |
| 我方中军 | 2 | 3 | 4 |
| 我方大营 | 3 | 4 | 5 |

**普攻寻敌规则：**
1. 取我方武将**攻击距离**（最小集固定为武将配置值）
2. 从攻击距离内的敌方存活单位中，选**距离最近**的目标
3. 同距离多个存活目标 → 按站位先手取（前锋 > 中军 > 大营）
4. 攻击距离内无敌方存活 → 该武将本回合无法普攻

**战法目标寻敌（纯伤害型主动战法）：**
- 单体战法：攻击距离内最近的存活敌军
- 群体战法：攻击距离内最近的目标及其身后相邻的存活目标（先手优先）
- 全体战法：全部存活敌军

> 最小集初版建议统一用「距离最近优先」规则，简化目标选择。

## 三、伤害模型（三部分相加）

> 依据《战斗伤害公式调研.md》。初版为「结构优先」：公式结构完全按调研走，具体曲线参数用固定常数先跑通，后续以真实战报 golden test 校准。

### 3.1 兵刃（物理）伤害

```
兵刃伤害 = 兵力基础伤害 + 攻击基础伤害 + 主要伤害
```

| 组成部分 | 公式（初版结构） | 说明 |
|----------|------------------|------|
| 兵力基础伤害 | `lookupTroopBase(troops, type)` | 仅与当前兵力有关；与伤害率无关；查表 |
| 攻击基础伤害 | `attacker.attack × 随机系数 × 伤害率 × 增减伤` | 无视防御；随机系数 ∈ {0.30…0.39}；100% 伤害率时 = 攻击×随机 |
| 主要伤害 | `unitDamage(troops) × 伤害率 × attrFactor(攻防差) × 增减伤` | unitDamage 为兵力曲线；attrFactor 见 3.3 |

- 结果向上取整到整数兵力。
- 伤害上限：`min(计算值, 目标当前兵力)`。

### 3.2 谋略（策略）伤害

```
谋略伤害 = 兵力基础伤害 + 谋略基础伤害 + 主要伤害
```

| 组成部分 | 公式（初版结构） | 说明 |
|----------|------------------|------|
| 兵力基础伤害 | `lookupTroopBase(troops, dotType)` | 谋略型低于兵刃型（10000 兵约 108 vs 211） |
| 谋略基础伤害 | `attacker.strategy × 系数 × 目标谋略因子 × 增减伤` | 与兵力、伤害率无关；目标谋略=0 时系数 0.5 |
| 主要伤害 | `unitDamage(troops) × 有效伤害率 × 目标谋略阶梯 × 增减伤` | 有效伤害率 = `基础率 + (谋略-80)×增长率`，1% 粒度「八舍九入」 |

**目标谋略阶梯**（减伤阈值）：目标谋略 ≥ 52 时按阶梯降低伤害（52/54/56/58/59/61… 每档约 -1%）。初版用分段线性近似，golden test 校准。

### 3.3 属性影响曲线（攻防差）

**兵刃**：`攻防差 = 攻击 - 目标防御`
- -70 ≤ 攻防差 ≤ 130：高收益区间，线性
- 区间外：边际递减，有上界

**初版占位实现（待校准）：**
```
attrFactor(diff) = clamp(0.3 + diff × 0.005, 0.1, 1.5)
```

### 3.4 增减伤因子

- 攻击基础伤害 + 主要伤害 =「可变伤害」，共享增减伤
- 增减伤总和 < **-90%** 时，最低保留 **10%** 伤害
- 初版：无增减伤战法，恒为 1.0，字段预留

### 3.5 兵力曲线（单位伤害）

| 兵力区间 | 走势 | 初版占位 |
|----------|------|----------|
| < 3500 | 增长快 | 用锚点插值 |
| 3500 ~ 7000 | 中速 | 锚点插值 |
| > 7000 | 增长明显变慢 | 锚点插值，趋近上界 |

**锚点（目标兵力充足时）：**

| 伤害类型 | 兵力=10000 约值 | 备注 |
|----------|----------------|------|
| 普通兵刃 | ≈ 211 | 与伤害率无关 |
| 动摇 | ≈ 211/3 | 初版不做 DOT，占位 |
| 普通谋略 | ≈ 108 | |
| 燃烧/恐慌/妖术 | ≈ 108/3 | 初版不做 DOT，占位 |

**初版占位：`unitDamage(troops) = baseRef × (troops / 10000)^0.55`**（结构符合「慢于线性、有上界」定性），baseRef 兵刃=211/谋略=108，golden test 锁定后替换。

### 3.6 伤害随机

- 攻击基础伤害：随机系数 ∈ {0.30, 0.31, …, 0.39}（步长 0.01，可复现）
- 固定随机种子 → 每次跑出完全一致结果（用户故事 B-04）

## 四、武将 / 战法数据模型（v0.1）

### 4.1 武将

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 唯一 ID |
| name | string | 名称 |
| faction | enum | 阵营（初版仅用于展示） |
| troopType | enum | 兵种（骑/步/弓；初版不参与克制计算，字段预留） |
| position | enum | 大营/中军/前锋 |
| attack / defense / strategy / speed | number | 四维（初版直接给面板值，不含等级成长） |
| attackRange | number | 攻击距离（1~5） |
| maxTroops | number | 初始兵力 |
| activeSkillId | string \| null | 主战法（主动类） |
| passiveSkillId | string \| null | 被动战法（最小集暂空） |
| commandSkillId | string \| null | 指挥战法（最小集暂空） |
| pursuitSkillId | string \| null | 追击战法（最小集暂空） |
| morale | number | 士气，预留字段，初版恒 100 不参与计算 |

### 4.2 战法（最小集：主动-纯伤害型）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 唯一 ID |
| name | string | 名称 |
| type | enum | active（初版仅 active） |
| range | number | 战法有效距离 |
| triggerRate | number | 发动率（0~1） |
| targetMode | enum | single / group / all |
| damageType | enum | physical / strategy |
| damageRate | number | 伤害率（100 表示 100%） |
| strategyScaled | boolean | 是否受谋略影响（true 时用有效伤害率公式） |
| growthRate | number | 谋略成长率（受谋略影响时用） |

**内置最小集战法（纯伤害型示例）：**

| 战法 | 类型 | 距离 | 发动率 | 目标 | 伤害类型 | 伤害率 | 说明 |
|------|------|------|--------|------|----------|--------|------|
| 突进 | 主动 | 3 | 30% | 单体 | 兵刃 | 115% | 最简普攻强化，覆盖 physical 伤害管线 |
| 凿穿 | 主动 | 2 | 25% | 单体 | 兵刃 | 135% | 不同距离/发动率档位 |
| 夹攻 | 主动 | 4 | 45% | 群体(1-2) | 谋略 | 89.6% 受谋略影响 | 覆盖 strategy 伤害 + 群体目标 |

> 三战法分别覆盖：兵刃单体 / 兵刃不同档位 / 谋略群体 + 受谋略成长。初版管线对「被动/指挥/追击」留接口但无实现。

### 4.3 内置固定测试集

`tests/fixtures.ts` 内置多套配置：

| 测试集 | 我方 | 敌方 | 验证点 |
|--------|------|------|--------|
| T1 纯普攻 | 1 将（无战法，攻 100/兵 10000） | 3 木桩 | 攻击基础随机系数分布；寻敌顺序 |
| T2 兵刃战法 | 3 将（各带 突进/凿穿） | 3 木桩 | 主动战法发动率；兵刃三部分伤害 |

| T4 兵力衰减 | 3 将满兵 | 3 木桩 | 兵力下降后伤害衰减曲线 |
| T5 距离寻敌 | 攻击距离 1 / 3 / 5 各一名 | 3 木桩 | 距离不足无法普攻；最近优先 |

## 六、技术架构

### 6.1 工程结构

```
战斗系统/
├─ src/
│  ├─ engine/
│  │  ├─ types.ts          # 武将/战法/战报/事件类型定义
│  │  ├─ rng.ts            # 可复现随机数（种子 → 序列）
│  │  ├─ formulas.ts       # 伤害公式（三部分相加、单位伤害曲线、攻防差曲线）
│  │  ├─ combat.ts         # 战斗主循环（准备回合 + 8 回合编排）
│  │  ├─ action.ts         # 单武将行动阶段（主动判定 → 普攻 → 追击）
│  │  ├─ target.ts         # 距离寻敌 / 目标选择
│  │  └─ report.ts         # 战报事件流 → JSON / 文本
│  ├─ data/
│  │  └─ skills.ts         # 内置最小集战法数据
│  └─ cli.ts               # CLI 入口：读配置 → 跑战斗 → 输出文本战报
├─ tests/
│  ├─ fixtures.ts          # 内置固定测试集（T1~T5）
│  ├─ golden.test.ts       # golden test（锁定输出，回归保护）
│  └─ formulas.test.ts     # 公式单元测试
├─ package.json            # tsx / vitest 等
└─ tsconfig.json
```

### 6.2 技术要点

| 项 | 方案 |
|----|------|
| 语言 | TypeScript（严格模式） |
| 运行时/测试 | Node + tsx（开发跑）；vitest（测试） |
| 随机 | 自研可复现 RNG（mulberry32 或简单 LCG），种子来自输入，`Math.random` 禁用 |
| 战报 | 事件流数组追加式生成；`report.ts` 负责渲染 JSON / 文本两种视图 |
| 引擎纯净 | 引擎零 UI 依赖，纯函数 + 输入配置，便于 golden test |
| 复现 | 同一配置 + 同一种子 → 字节级一致输出 |

### 6.3 golden test 策略

1. 内置 T1~T5 固定测试集，每套固定种子
2. 首次运行生成 `__snapshots__/golden.json`，后续运行 diff 比对
3. 任何引擎改动导致输出变化 → 测试失败，人工确认是有意变更
4. 后续接入真实战报数据，替换占位曲线参数后更新 snapshot
