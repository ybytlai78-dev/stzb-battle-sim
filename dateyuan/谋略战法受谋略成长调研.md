## 一、机制说明

### 1.1 基础值锚点

战法描述中的数值 = **谋略 80** 时的效果（伤害率 / 恢复率 / 增减伤百分比等）。

### 1.2 通用计算公式

**谋略 ≥ 80：**

```
实际数值 = round(基础值 + 成长率 × (谋略 - 80))
```

**谋略 < 80：**

```
实际数值 = round(基础值 × 0.4 + (基础值 × 0.6) × (谋略 / 80))
```

- 伤害率 / 恢复率另需按 **1%** 粒度「八舍九入」取整（见大明州《率土秘卷》系列）
- 例：**大赏三军** 满级基础增伤 **30%**，成长率 **0.15%/点**；谋略 150 时 ≈ `30 + 0.15×70 = 40.5 → 41%`

### 1.3 恢复值计算公式（v0.14 补全，替代原「目标最大兵力 × 恢复率」错误实现）

权威来源：十面埋伏《率土秘卷一：恢复效果》（[知乎](https://zhuanlan.zhihu.com/p/454193204)，公式图 OCR 复核）：

```
恢复值 = floor( round( 300×施法者兵力 / (3500+施法者兵力) ) × 恢复率/100 × (1 + 恢复提高效果) )
```

- 单位伤害曲线与伤害公式共用；⚠️ 原文是 **300×兵力（乘号）**，非 `(300+兵力)`
- **实战验证**（文章评论区 2025-06，与战报分毫不差）：皇裔流离 谋略 269 → 恢复率 181%；9500 兵 → round(219.23)=219；219×1.81 = 396.39 → **396**
- 状态类恢复（休整/持续急救）的变量取「状态被施加那一刻」（挂上时冻结）；主动恢复取结算时施法者当前兵力
- 恢复提高效果极罕见（博浪【抖擞】/锻造【仁心】），引擎未建模按 1；恢复量还受伤兵池/兵力缺口截断
- 模拟器（FlxSNX `calcRecover`）实现一致：`floor( round(300×arms/(3500+arms)) × rate/100 × 1 )`
- 遗留：评论区反馈主动恢复类（增援/合流）与公式不符（目标兵力越少恢复越多），待真实战报校准

### 1.3 效果分类

| 类别 | 典型战法 | 成长率含义 |
|------|----------|------------|
| 增减伤% | 大赏三军、神兵天降、避其锋芒 | 每 +1 谋略，增减伤百分比 +N |
| 伤害率 | 落雷、楚歌四起、众谋不懈 | 每 +1 谋略，伤害率 +N% |
| 恢复率 | 三军之众、重整旗鼓 | 每 +1 谋略，恢复率 +N% |
| 属性数值 | 伐谋、筹策绝道 | 每 +1 谋略，降低/提高属性 +N 点 |

> **恢复率公式联网复核（2026-08，大明州攻略 4470 / 知乎 377462754 / FlxSNX 模拟器交叉验证）**：
> 公式与本地 1.2 一致——实际恢复率 = round(基础恢复率 + 恢复率增长率×(谋略-80))，1% 粒度八舍九入，无误差。
> 补全武将自带恢复战法成长率：**皇裔流离（刘备）68 / 0.6**、**金匮要略（张机）80 / 0.75**（减伤 20.4 / 0.13）。
> 参考模拟器 `calcRecoverRate` 用 `Math.floor(int×growRate)` 截断且谋略<80 无 0.4/0.6 折减——属社区简化，以本表（大明州/本地文档）为准。
> 恢复量：模拟器用 `单位伤害曲线(施法者兵力) × 实际恢复率`；本引擎 heal 用 `目标最大兵力 × 恢复率`（差异待后续校准）。
