公式参考（formulas.ts 逐行对应）

兵刃伤害

伤害 = 兵力基础 + 攻击基础 + 主要伤害

兵力基础 = round( 373·兵 / (7700+兵) )      // 与伤害率无关
攻击基础 = 攻击 × 随机{0.30..0.39} × (伤害率/100) × 增减伤   // 与兵力无关
主要伤害 = unit(兵) × (伤害率/100) × 攻防差(攻击−防御) × 增减伤
unit(兵)  = 300·兵 / (3500+兵)
攻防差因子：diff≥0 → 3−500/(250+diff)；diff<0 → 100/(100−diff)。
随机仅来自攻击基础系数（连续普攻波动可达 ≈30%）。

谋略伤害

伤害 = 兵力基础 + 谋略基础 + 主要伤害

兵力基础 = round( 178·兵 / (6459+兵) )      // 与伤害率无关
谋略基础 = 谋略 × 0.5 × 目标谋略减伤 × 增减伤    // 与兵力、伤害率无关
主要伤害 = unit(兵) × 有效伤害率 × 目标谋略减伤 × 增减伤
有效伤害率 = roundRate(基础率 + (谋略−80)·成长率)
目标谋略减伤（只看目标谋略）：谋略≤50 → 1；否则 ceil(100−(75−9375/(75+谋略)))/100。
有效伤害率按 1% 粒度「八舍九入」取整。锚点：兵力 9000 / 10000 处为常见 40 级满兵场景。
