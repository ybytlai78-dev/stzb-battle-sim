# 敌对队伍集 · 投放箱

把你截的**敌方阵容**截图丢进这个文件夹（选中游戏里的「敌方」页签再截），然后对 AI 说一句「**扫图**」。

## 会发生什么

1. AI 逐张读图 → 出一份识别结果 JSON（三将 / 位置 / 等级 / 三个战法 / 兵种特性 / 宝物，固定格式）；
2. 脚本按库严格校验（武将名、战法名、主战法断言、特性、宝物只认稀世 + 词条归属）；
3. **图片连同识别结果被移动到隔壁 `已识别敌对队伍集/`**，所以这个文件夹处理完就是空的 —— 空 = 没有待识别的图。

## 注意

- **识别失败的图会留在这里**（你自己就看得出哪些没识别成），不会被悄悄丢掉。
- 命名随意，建议「敌方-三将名」，例如 `敌方-陈宫张宁吕蒙.png`；识别结果用同名 `.json` 存在归档目录，好对照。
- 截图**不入库**（`.gitignore` 已忽略本目录与归档目录下的图片），只有识别结果 JSON 入 git。
- 支持 png / jpg / jpeg / webp。

口径与校验规则见 `docs/截图识别-敌对队伍集.md`。
